### Problem Statement
Inverse problem for the 2D steady-state incompressible Navier–Stokes equations in a lid-driven cavity. The goal is to infer the unknown Reynolds number \(Re\) and reconstruct the hidden \(y\)-velocity field \(v(x,y)\) using only sparse, noisy observations of the \(x\)-velocity component \(u(x,y)\). The reference “truth” corresponds to \(Re=500\), for which a high-fidelity solution is provided. The inverse model must not use exact Dirichlet boundary imposition and must not use \(v\) or \(p\) observations as training data.

### Equation(s)

Steady, incompressible 2D Navier–Stokes:

- Incompressibility:
\[
\nabla \cdot \mathbf{u} = 0
\]

- Momentum:
\[
(\mathbf{u} \cdot \nabla)\mathbf{u} = -\nabla p + \frac{1}{Re}\nabla^2 \mathbf{u}
\]

where \(\mathbf{u} = (u(x,y), v(x,y))\) and \(p(x,y)\) is the kinematic pressure. The Reynolds number \(Re\) is unknown and will be inferred, with a prior range \(Re \in [300, 525]\). The true value used for validation is \(Re_{\text{true}} = 500\).

### Domain

- Spatial domain:
\[
(x,y) \in [0,1] \times [0,1]
\]

- Steady-state (no time dependence).

### Boundary Conditions

Lid-driven cavity with a smoothed moving lid at the top:

- Top lid (\(y=1\)):
  - Streamwise velocity:
    \[
    u(x,1) = 1 - \frac{\cosh(C_0(x-0.5))}{\cosh(0.5 C_0)}, \quad C_0 = 50
    \]
  - Normal velocity:
    \[
    v(x,1) = 0
    \]

- Bottom wall (\(y=0\)) – no-slip:
  \[
  u(x,0) = 0, \quad v(x,0) = 0
  \]

- Left wall (\(x=0\)) – no-slip:
  \[
  u(0,y) = 0, \quad v(0,y) = 0
  \]

- Right wall (\(x=1\)) – no-slip:
  \[
  u(1,y) = 0, \quad v(1,y) = 0
  \]

- These Dirichlet boundary conditions must not be imposed exactly (no “hard” or exact boundary enforcement). They should enter only via “soft” mechanisms (e.g., penalty terms or physics regularization), not as hard constraints.

  Re \in [300, 525]
