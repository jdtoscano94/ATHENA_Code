**1. Problem Statement**  
Solve the 2D compressible Euler equations with gravity for Rayleigh–Taylor instability in a rectangular domain with periodicity in \(x\) and reflective/free-slip walls in \(y\), from \(t=0\) to \(t=3\).

---

## **1. Mathematical Specification (Code-Ready Extraction)**

### **Governing Equations:**
Let conservative state \(\mathbf{U}=(\rho,\rho u,\rho v,E)^T\), total energy \(E=\rho e+\tfrac12\rho(u^2+v^2)\), and ideal-gas closure
\[
p=(\gamma-1)\left(E-\tfrac12\rho(u^2+v^2)\right),\qquad \gamma=1.4.
\]
2D Euler with gravity \(\mathbf{g}=(0,g)^T\), \(g=1.0\) in \(+\hat y\):
\[
\partial_t
\begin{pmatrix}
\rho\\ \rho u\\ \rho v\\ E
\end{pmatrix}
+
\partial_x
\begin{pmatrix}
\rho u\\ \rho u^2+p\\ \rho u v\\ (E+p)u
\end{pmatrix}
+
\partial_y
\begin{pmatrix}
\rho v\\ \rho u v\\ \rho v^2+p\\ (E+p)v
\end{pmatrix}
=
\begin{pmatrix}
0\\ 0\\ \rho g\\ \rho g v
\end{pmatrix}.
\]

### **Domain:**
\[
(x,y)\in[0,0.25]\times[0,1.0],\qquad t\in[0,3.0].
\]

### **Boundary Conditions:**
- **\(x=0\) and \(x=0.25\):** Periodic for all conserved variables.  
- **\(y=0\) and \(y=1\):** Reflective / free-slip wall:
  \[
  v=0\ \text{at}\ y\in\{0,1\},\quad \text{and tangential velocity }u\ \text{is mirrored (free-slip)}.
  \]
  (Implemented via reflective states: normal momentum \(\rho v\) changes sign, \(\rho u,\rho,E\) mirrored consistently.)

### **Initial Conditions:**

**Density:**
\[
\rho(x,y)=\rho(y)= 2.0 + (1.0-2.0)\cdot \frac12\left(1+\tanh\!\left(50(y-0.5)\right)\right).
\]

**Pressure (given piecewise hydrostatic profile):**
\[
p(x,y)=p(y)=
\begin{cases}
2y+1, & y<0.5,\\
y+1.5, & y\ge 0.5.
\end{cases}
\]

**Velocities:**
\[
u(x,y)=0,
\]
\[
c(x,y)=\sqrt{\gamma\,\frac{p(y)}{\rho(y)}},
\]
\[
v(x,y)= -0.025\; c(x,y)\; \cos(8\pi x)\; \sin(\pi y)^6.
\]

**Total energy:**
\[
E(x,y)=\frac{p(x,y)}{\gamma-1}+\frac12\rho(x,y)\left(u(x,y)^2+v(x,y)^2\right).
\]

### **Constants & Parameters:**
\[
\gamma=1.4,\quad g=1.0,\quad \rho_{heavy}=2.0,\quad \rho_{light}=1.0.
\]

### **Expected Physics:**
Classical RTI: heavy fluid below light fluid under acceleration in \(+y\) is unstable; interfacial roll-up develops, generating strong density gradients and eventually shocks/acoustic activity due to compressibility.

---

Physics justification: compressible, inviscid, shock-capable, wall boundaries + periodic direction, sharp interface gradients \(\Rightarrow\) DGSEM with shock capturing is the robust choice.

@inline function initial_condition_rt(x, t, equations::CompressibleEulerEquations2D)
    x_coord, y_coord = x[1], x[2]
    
    # Density profile
    rho = 2.0 + (1.0 - 2.0) * 0.5 * (1.0 + tanh(50.0 * (y_coord - 0.5)))
    
    # Pressure profile (piecewise hydrostatic)
    if y_coord < 0.5
        p = 2.0 * y_coord + 1.0
    else
        p = y_coord + 1.5
    end
    
    # Velocity profile
    u = 0.0
    c = sqrt(equations.gamma * p / rho)
    v = -0.025 * c * cos(8.0 * pi * x_coord) * sin(pi * y_coord)^6
    
    return prim2cons(SVector(rho, u, v, p), equations)
end

@inline function source_terms_rt(u, x, t, equations::CompressibleEulerEquations2D)
    g = 1.0

    v2 = rho_v2 / rho
    
    return SVector(0.0, 0.0, rho * g, rho * g * v2)
end
