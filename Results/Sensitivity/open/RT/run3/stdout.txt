**1. Problem Statement**

2D inviscid compressible Euler simulation of the single-mode Rayleigh-Taylor Instability. Gravity acts in $+y$, placing the heavy fluid ($\rho=2.0$, bottom) in effective "overhang" of the light fluid ($\rho=1.0$, top) — an unstable configuration. A single-mode velocity perturbation seeds the interface; the goal is to capture the linear growth phase, the nonlinear bubble/spike regime, and the late-time mixing layer up to $t=3.0$.

---

**1. Mathematical Specification (Code-Ready Extraction)**

* **Governing Equations:** 2D Compressible Euler with gravitational source ($+y$):
$$
\frac{\partial}{\partial t}\begin{pmatrix} \rho \\ \rho u \\ \rho v \\ E \end{pmatrix}
+ \frac{\partial}{\partial x}\begin{pmatrix} \rho u \\ \rho u^2 + p \\ \rho u v \\ u(E+p) \end{pmatrix}
+ \frac{\partial}{\partial y}\begin{pmatrix} \rho v \\ \rho u v \\ \rho v^2 + p \\ v(E+p) \end{pmatrix}
= \begin{pmatrix} 0 \\ 0 \\ \rho g \\ \rho g\, v \end{pmatrix}
$$
with equation of state $p = (\gamma - 1)\left(E - \tfrac{1}{2}\rho(u^2 + v^2)\right)$.

* **Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $t \in [0, 3.0]$.

* **Boundary Conditions:**
  * $x$-direction: Periodic.
  * $y=0$ and $y=1$: Reflective / free-slip walls (no-penetration, $v=0$).

* **Initial Conditions:**
$$
\rho(x,y) = 2.0 + (1.0 - 2.0)\cdot \frac{1}{2}\left(1 + \tanh\left(50\,(y - 0.5)\right)\right)
$$
$$
p(x,y) = \begin{cases} 2y + 1, & y < 0.5 \\ y + 1.5, & y \geq 0.5 \end{cases}
$$
$$
u(x,y) = 0
$$
$$
v(x,y) = -0.025\, c(x,y)\, \cos(8\pi x)\, \left[\sin(\pi y)\right]^6, \qquad c(x,y) = \sqrt{\frac{\gamma\, p(x,y)}{\rho(x,y)}}
$$

* **Constants & Parameters:** $\gamma = 1.4$; $g = 1.0$ (source adds momentum in $+y$); $\rho_{heavy}=2.0$, $\rho_{light}=1.0$; interface at $y=0.5$; interface smoothing parameter $50$; perturbation amplitude $0.025$; perturbation wavenumber $8\pi$ (single mode over $L_x = 0.25$); $\mu = 0$, $k = 0$.

* **Expected Physics:**
  * $t \lesssim 1$: Linear phase — exponential growth of the seeded mode; light-fluid bubbles descend ($-y$), heavy-fluid spikes ascend ($+y$).
  * $t \approx 1\text{–}2$: Nonlinear bubble/spike fronts form; Kelvin-Helmholtz roll-up on spike flanks.
  * $t \approx 2\text{–}3$: Broadening mixing layer, secondary instabilities, vortical structures; possible weak compressible shocks from spike deceleration.
  * Minor initial acoustic transient from the (standard) slight mismatch between the smoothed $\rho$ and the piecewise hydrostatic $p$; decays quickly and is dominated by RT growth.

**2. Strategic Methodology**

* **Exact solution feasibility: NOT FEASIBLE.** The system is a nonlinear, multi-dimensional hyperbolic PDE with a source term. The Method of Characteristics does not extend to 2D nonlinear systems (characteristics form a multi-parameter family with no closed-form envelope), and no analytical solution exists for the nonlinear RT mixing process. Ground truth must be numerical with high resolution.
* **Selection: Discontinuous Galerkin Spectral Element Method in 2D plus time.** Rationale: (i) hyperbolic system with discontinuity-sharpening interfaces — DG's locality and shock-capturing support are essential; (ii) mixed BCs (periodic in $x$, walls in $y$) are natively supported; (iii) AMR can track the evolving mixing layer efficiently; (iv) entropy-stable DG handles the strong density contrast without spurious oscillations. Fourier Spectral is rejected (non-periodic in $y$; steep gradients/mixing). Steady CG is rejected (transient problem).

        x, t, equations::CompressibleEulerEquations2D)

function save_npz_file(integrator)
    semi = integrator.p
    t = integrator.t

    # Reconstruct all conservative and primitive variables on the same grid.
    pd_cons = PlotData2D(integrator.u, semi, solution_variables=cons2cons)
    pd_prim = PlotData2D(integrator.u, semi, solution_variables=cons2prim)

    conservative_rho = getindex.(pd_cons.data, 1)
    rho_u = getindex.(pd_cons.data, 2)
    rho_v = getindex.(pd_cons.data, 3)
    rho_e = getindex.(pd_cons.data, 4)

    rho = getindex.(pd_prim.data, 1)
    u = getindex.(pd_prim.data, 2)
    v = getindex.(pd_prim.data, 3)
    p = getindex.(pd_prim.data, 4)

                            "rho_u" => rho_u,
                            "rho_v" => rho_v,
                            "rho_e" => rho_e,
                            "state_vector" => copy(integrator.u)))

    println("Saved: $(basename(filename))")
    return nothing
end

function condition_save_npz(u, t, integrator)
    index = npz_next_save_index[]
    index <= length(npz_save_times) || return false

    return t >= npz_save_times[index] - 1.0e-12
end

function affect_save_npz!(integrator)
    save_npz_file(integrator)

    # Advance past every scheduled time reached by the current integrator step.
    while npz_next_save_index[] <= length(npz_save_times) &&
          integrator.t >= npz_save_times[npz_next_save_index[]] - 1.0e-12
        npz_next_save_index[] += 1
    end

    return nothing
end

function init_save_npz(cb, u, t, integrator)
    npz_next_save_index[] = 2
    save_npz_file(integrator)
end

# Scientific Strategy Report: 2D Compressible Euler — Rayleigh-Taylor Instability

---

## 1. Problem Statement

Single-mode Rayleigh-Taylor instability of the inviscid compressible Euler equations: a heavy fluid ($\rho=2.0$) rests below a light fluid ($\rho=1.0$) with effective acceleration ($g=+1.0$ in $y$) destabilizing the interface at $y=0.5$. A single-wavelength velocity perturbation seeds the instability. Target: high-fidelity ground truth on $[0,0.25]\times[0,1]$ for $t\in[0,3]$, resolving the linear growth $\to$ nonlinear spike/bubble $\to$ Kelvin-Helmholtz roll-up cascade.

---

## 2. Mathematical Specification (Code-Ready Extraction)

**Governing Equations** (2D compressible Euler with gravitational source):
$$
\partial_t \rho + \partial_x(\rho u) + \partial_y(\rho v) = 0
$$
$$
\partial_t(\rho u) + \partial_x(\rho u^2 + p) + \partial_y(\rho u v) = 0
$$
$$
\partial_t(\rho v) + \partial_x(\rho u v) + \partial_y(\rho v^2 + p) = \rho g
$$
$$
\partial_t E + \partial_x\big(u(E+p)\big) + \partial_y\big(v(E+p)\big) = \rho g v
$$
with equation of state $E = \dfrac{p}{\gamma-1} + \dfrac{1}{2}\rho(u^2+v^2)$.

**Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $\quad t \in [0, 3.0]$

**Boundary Conditions:**
- $x \in \{0, 0.25\}$: Periodic
- $y = 0$ and $y = 1$: Reflective / free-slip wall (no-penetration: $v = 0$; mirror $u$, tangential momentum; reflect $\rho, p$)

**Initial Conditions** (exact, at $t=0$):
$$
\rho(x,y) = 2.0 + (1.0 - 2.0)\cdot\frac{1}{2}\left(1 + \tanh\left(50(y - 0.5)\right)\right)
$$
$$
p(x,y) = \begin{cases} 2y + 1 & \text{if } y < 0.5 \\ y + 1.5 & \text{if } y \geq 0.5 \end{cases}
$$
$$
u(x,y) = 0
$$
$$
v(x,y) = -0.025 \cdot c(y) \cdot \cos(8\pi x) \cdot \sin^6(\pi y), \qquad c(y) = \sqrt{\frac{\gamma\, p(y)}{\rho(y)}}
$$
$$
E(x,y) = \frac{p(y)}{\gamma - 1} + \frac{1}{2}\,\rho(x,y)\, v(x,y)^2
$$

**Constants & Parameters:**
| Parameter | Value |
|---|---|
| $\gamma$ | $1.4$ |
| Gravity vector $\mathbf{g}$ | $[0, +1.0]^T$ (momentum source $\rho g$ in $+y$; energy source $\rho g v$) |
| $\rho_{heavy},\ \rho_{light}$ | $2.0,\ 1.0$ |
| Interface position / smoothing | $y = 0.5$, $\tanh$ width parameter $50$ |
| Perturbation amplitude / wavenumber | $0.025$, $8\pi$ (one wavelength across $x$-domain) |
| Atwood number | $A = 1/3$ |

**Expected Physics:** Exponential linear growth of the seeded mode ($t \lesssim 1$); heavy-fluid spike ascends and light-fluid bubble descends ($t \approx 1$–$2$); nonlinear mushroom cap with Kelvin-Helmholtz roll-up vortices on the spike flanks ($t \approx 2$–$3$); spike interaction with the upper wall near $t = 3$. Contact discontinuity (material interface) is the dominant sharp feature; shear layers generate secondary KH instabilities.

## 3. Strategic Methodology

**Exact solution feasibility: NOT FEASIBLE.** The full nonlinear 2D Euler system with gravity, wall boundaries, and a finite-amplitude evolving interface has no closed-form solution. The Method of Characteristics is restricted to 1D/simple-wave hyperbolic problems — here the dynamics are genuinely multi-dimensional (vorticity deposition at the shear layer, KH roll-up, shocklet formation), precluding any characteristics-based exact solution. Linear RTI stability theory yields only early-time growth rates, not the full evolution. **A numerical method is mandatory.**

**Method Selection:**
- *Fourier Spectral:* Rejected — domain is non-periodic in $y$ (reflective walls).
- *DGSEM 1D:* Rejected — genuinely 2D problem.
- *Steady CG 2D:* Rejected — strongly time-dependent transient.

# ## Methodology: Gap-Free Nearest-Neighbor Lattice Projection
# Projects the scattered DG visualization samples onto a regular grid for
# continuous heatmap rendering. The default raster dimensions follow the
# native sampled coordinate counts, avoiding unnecessary downsampling.
#
# Each occupied pixel retains the value of its nearest sample. Remaining
# pixels are filled from the nearest occupied pixels using a multi-source
# grid traversal. Consequently, the returned matrix contains no NaN entries,
# empty rows, or empty columns. Matrix rows correspond to y and columns to x.

function rasterize_data(x, y, z, nx=nothing, ny=nothing)
    x_values = vec(x)
    y_values = vec(y)
    z_values = vec(z)

    @assert length(x_values) == length(y_values) == length(z_values)
    @assert !isempty(z_values)
    @assert all(isfinite, x_values)
    @assert all(isfinite, y_values)
    @assert all(isfinite, z_values)

    # Match the native sample density unless explicit dimensions are supplied.
    # Rounding merges coordinates repeated at shared element boundaries.
    if nx === nothing
        nx = max(2, length(unique(map(value -> round(value, digits=12),
                                      x_values))))
    end
    if ny === nothing
        ny = max(2, length(unique(map(value -> round(value, digits=12),
                                      y_values))))
    end
    @assert nx >= 2 && ny >= 2

    x_min, x_max = 0.0, 0.25
    y_min, y_max = 0.0, 1.0
    x_grid = collect(range(x_min, x_max, length=nx))
    y_grid = collect(range(y_min, y_max, length=ny))
    dx = (x_max - x_min) / (nx - 1)
    dy = (y_max - y_min) / (ny - 1)

    # Retain the closest sample assigned to each pixel instead of averaging
    # across a discontinuous material interface.
    grid = fill(NaN, ny, nx)
    nearest_distance = fill(Inf, ny, nx)

    for k in eachindex(x_values)
        i = clamp(round(Int, (x_values[k] - x_min) / dx) + 1, 1, nx)
        j = clamp(round(Int, (y_values[k] - y_min) / dy) + 1, 1, ny)
        distance = (x_values[k] - x_grid[i])^2 +
                   (y_values[k] - y_grid[j])^2

        if distance < nearest_distance[j, i]
            nearest_distance[j, i] = distance
            grid[j, i] = z_values[k]
        end
    end

    any(isfinite, grid) || error("Rasterization received no valid samples.")

    # Multi-source breadth-first traversal fills every unoccupied pixel from
    # a neighboring occupied pixel. Every pixel is enqueued at most once.
    queue_i = Vector{Int}(undef, nx * ny)
    queue_j = Vector{Int}(undef, nx * ny)
    head = 1
    tail = 0

    for j in 1:ny, i in 1:nx
        if isfinite(grid[j, i])
            tail += 1
            queue_i[tail] = i
            queue_j[tail] = j
        end
    end

    while head <= tail
        i = queue_i[head]
        j = queue_j[head]
        head += 1

        for (ii, jj) in ((i - 1, j), (i + 1, j),
                         (i, j - 1), (i, j + 1))
            if 1 <= ii <= nx && 1 <= jj <= ny && !isfinite(grid[jj, ii])
                grid[jj, ii] = grid[j, i]
                tail += 1
                queue_i[tail] = ii
                queue_j[tail] = jj
            end

function interface_metrics(rho_values, y_values)
    rho_vec = vec(rho_values)
    y_vec = vec(y_values)

    # The apex is the highest point containing heavy fluid. The mixing-layer
    # width is bounded by this apex and the lowest point containing light fluid.
    heavy = rho_vec .> 1.5
    light = rho_vec .<= 1.5

    apex = any(heavy) ? maximum(y_vec[heavy]) : NaN
    lowest_light = any(light) ? minimum(y_vec[light]) : NaN
    width = (isfinite(apex) && isfinite(lowest_light)) ?
            max(0.0, apex - lowest_light) : NaN

    return apex, width
end

function wall_velocity_extrema(y_values, v_values, wall_y)
    y_vec = vec(y_values)
    v_vec = vec(v_values)
    distances = abs.(y_vec .- wall_y)

    indices = findall(d -> d <= 1.0e-10, distances)
    if isempty(indices)
        # Fall back to the closest plotted wall plane if coordinates differ by
        # more than roundoff from the exact wall location.
        closest_distance = minimum(distances)
        indices = findall(d -> d <= closest_distance + 1.0e-12, distances)
    end

    return extrema(v_vec[indices])
end

function estimate_filament_thickness(rho_values, x_values, y_values)
    rho_vec = vec(rho_values)
    x_vec = vec(x_values)
    y_vec = vec(y_values)

    if length(rho_vec) != length(x_vec) ||
       length(rho_vec) != length(y_vec) || length(rho_vec) < 2
        return NaN
    end

    # Estimate the sharpest resolved material transition from vertical density
    # gradients. For unit density contrast, 0.8/max|drho/dy| is the approximate
    # 10--90% transition thickness. This supplies a consistent resolution metric
    # for the current run and the stored baseline despite different AMR grids.
    x_keys = round.(x_vec, digits=12)
    order = sortperm(1:length(rho_vec),
                     by=i -> (x_keys[i], y_vec[i]))
    max_gradient = 0.0

    for k in 2:length(order)
        previous = order[k - 1]
        current = order[k]

        if x_keys[previous] == x_keys[current]
            dy = y_vec[current] - y_vec[previous]
            if dy > 0.0
                drho = abs(rho_vec[current] - rho_vec[previous])
                max_gradient = max(max_gradient, drho / dy)
            end
        end
    end

    max_gradient > 0.0 || return NaN
    return 0.8 / max_gradient
end

function polydeg5_baseline_snapshot(t)
    baseline_dir = joinpath(@__DIR__, "data_npz_polydeg5")
    isdir(baseline_dir) || return nothing

    files = sort([joinpath(baseline_dir, file) for file in readdir(baseline_dir)
                  if endswith(file, ".npz")])
    isempty(files) && return nothing

    times = Float64[diagnostic_scalar(npzread(file)["t"]) for file in files]
    index = argmin(abs.(times .- t))

    # Permit the small callback-time overshoot possible in the archived run.
    abs(times[index] - t) <= 0.025 || return nothing

    return (data=npzread(files[index]), t=times[index])
end

function compare_polydeg5_baseline(t, current)
    baseline = polydeg5_baseline_snapshot(t)

    if baseline === nothing
        if t == 3.0
            println("  polydeg=5 baseline unavailable in data_npz_polydeg5; " *
                    "p-convergence comparison skipped.")
        end
        return nothing
    end

    data = baseline.data
    baseline_apex, baseline_width = interface_metrics(data["rho"], data["y"])
    delta_apex = current.interface_apex - baseline_apex
    delta_width = current.mixing_layer_width - baseline_width

    Printf.@printf("  polydeg=5 comparison (baseline t=%.5f): " *
                   "Δapex=%.6e, Δmixing_width=%.6e\n",
                   baseline.t, delta_apex, delta_width)

    if t == 3.0
        baseline_filament = estimate_filament_thickness(data["rho"],
                                                        data["x"], data["y"])
        delta_filament = current.filament_thickness - baseline_filament

                       "polydeg=5=%.6e, Δfilament=%.6e\n",
                       current.filament_thickness, baseline_filament,
                       delta_filament)

        apex_unchanged = isfinite(delta_apex) &&
                         abs(delta_apex) <=
                         1.0e-3 * max(1.0, abs(current.interface_apex))
        width_unchanged = isfinite(delta_width) &&
                          abs(delta_width) <=
                          1.0e-3 * max(1.0, abs(current.mixing_layer_width))
        filament_unchanged = isfinite(delta_filament) &&
                             abs(delta_filament) <=

            println("  p=6 metrics are unchanged within tolerance; residual " *
                    "smearing is controlled by FV blending / the AMR level " *

        end
    end

    return nothing
end

function save_npz_file(integrator)
    semi = integrator.p
    t = integrator.t

    @assert all(isfinite, integrator.u) "Non-finite conservative state at t=$t"

    # Reconstruct all conservative and primitive variables on the same grid.
    pd_cons = PlotData2D(integrator.u, semi, solution_variables=cons2cons)
    pd_prim = PlotData2D(integrator.u, semi, solution_variables=cons2prim)

    conservative_rho = getindex.(pd_cons.data, 1)
    rho_u = getindex.(pd_cons.data, 2)
    rho_v = getindex.(pd_cons.data, 3)
    rho_e = getindex.(pd_cons.data, 4)

    rho = getindex.(pd_prim.data, 1)
    u = getindex.(pd_prim.data, 2)
    v = getindex.(pd_prim.data, 3)
    p = getindex.(pd_prim.data, 4)

    rho_min = minimum(rho)
    p_min = minimum(p)
    @assert rho_min > 0.0 "Non-positive density at t=$t: min(rho)=$rho_min"
    @assert p_min > 0.0 "Non-positive pressure at t=$t: min(p)=$p_min"

    # Use DG quadrature rather than point sums on the nonuniform plot grid.
    mass = Trixi.integrate(diagnostic_mass, integrator.u, semi)
    energy = Trixi.integrate(diagnostic_energy, integrator.u, semi)
    source_work = Trixi.integrate(diagnostic_source_work, integrator.u, semi)

    if !isfinite(diagnostic_initial_mass[])
        diagnostic_initial_mass[] = mass
    end
    mass_drift = mass - diagnostic_initial_mass[]
    relative_mass_drift = abs(mass_drift) / abs(diagnostic_initial_mass[])

    # Compare the discrete energy tendency with the trapezoidal interval-mean
    # source work. This uses the same time interval for both quantities.
    energy_tendency = NaN
    source_work_interval_mean = NaN
    energy_balance_residual = NaN
    integrated_energy_balance_residual = NaN

    if isfinite(diagnostic_previous_time[]) && t > diagnostic_previous_time[]
        dt = t - diagnostic_previous_time[]
        energy_difference = energy - diagnostic_previous_energy[]
        energy_tendency = energy_difference / dt
        source_work_interval_mean =
            0.5 * (source_work + diagnostic_previous_source_work[])
        energy_balance_residual = energy_tendency - source_work_interval_mean
        integrated_energy_balance_residual =
            energy_difference - source_work_interval_mean * dt
    end

    bottom_wall_v = wall_velocity_extrema(pd_prim.y, v, 0.0)
    top_wall_v = wall_velocity_extrema(pd_prim.y, v, 1.0)
    bottom_wall_maxabs = max(abs(bottom_wall_v[1]), abs(bottom_wall_v[2]))
    top_wall_maxabs = max(abs(top_wall_v[1]), abs(top_wall_v[2]))

    interface_apex, mixing_layer_width = interface_metrics(rho, pd_prim.y)

    output_time = npz_visualization_times[
        argmin(abs.(npz_visualization_times .- t))]
    is_output_time = abs(t - output_time) <= 0.025

    end

    current_metrics = (interface_apex=interface_apex,
                       mixing_layer_width=mixing_layer_width,
                       filament_thickness=filament_thickness,
                       total_mass=mass,
                       energy_tendency=energy_tendency,
                       source_work=source_work,
                       energy_balance_residual=energy_balance_residual)

    Printf.@printf("RTI diagnostics t=%.5f: min(rho)=%.6e, min(p)=%.6e\n",
                   t, rho_min, p_min)
    if is_output_time
        Printf.@printf("  mandated output-time certification: t=%.2f\n",
                       output_time)
    end
    Printf.@printf("  no-penetration: max|v|(y=0)=%.6e, " *
                   "max|v|(y=1)=%.6e\n",
                   bottom_wall_maxabs, top_wall_maxabs)
    Printf.@printf("  mass=%.12e, relative mass drift |M-M0|/M0=%.6e\n",
                   mass, relative_mass_drift)
    Printf.@printf("  energy=%.12e, dE/dt=%.6e, instantaneous source work=%.6e\n",
                   energy, energy_tendency, source_work)
    Printf.@printf("  interval-mean source work=%.6e, " *
                   "energy-balance residual=%.6e, integrated residual=%.6e\n",
                   source_work_interval_mean, energy_balance_residual,
                   integrated_energy_balance_residual)
    Printf.@printf("  interface apex=%.6e, mixing-layer width=%.6e\n",

function condition_save_npz(u, t, integrator)
    index = npz_next_save_index[]
    index <= length(npz_save_times) || return false

    return t >= npz_save_times[index] - 1.0e-12
end

function affect_save_npz!(integrator)
    save_npz_file(integrator)

    # Advance past every scheduled time reached by the current integrator step.
    while npz_next_save_index[] <= length(npz_save_times) &&
          integrator.t >= npz_save_times[npz_next_save_index[]] - 1.0e-12
        npz_next_save_index[] += 1
    end

    return nothing
end

function init_save_npz(cb, u, t, integrator)
    npz_next_save_index[] = 2
    diagnostic_initial_mass[] = NaN
    diagnostic_previous_time[] = NaN
    diagnostic_previous_energy[] = NaN
    diagnostic_previous_source_work[] = NaN
    save_npz_file(integrator)
end

save_npz_callback = DiscreteCallback(condition_save_npz,
