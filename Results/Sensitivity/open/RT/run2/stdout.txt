**1. Problem Statement**
2D inviscid compressible Euler Rayleigh–Taylor Instability (RTI). A heavy fluid ($\rho=2$) lies below $y=0.5$ and a light fluid ($\rho=1$) above; with gravity acting in $+y$, the heavy fluid is gravitationally "overlying" the light fluid — an unstable configuration. A single-mode velocity perturbation seeds the instability, which must be evolved to $t=3.0$ through the linear, nonlinear bubble/spike, and mixing phases.

---

**1. Mathematical Specification (Code-Ready Extraction)**

* **Governing Equations:** 2D Compressible Euler with gravity source:
$$
\partial_t \mathbf{U} + \partial_x \mathbf{F}(\mathbf{U}) + \partial_y \mathbf{G}(\mathbf{U}) = \mathbf{S}(\mathbf{U}), \qquad \mathbf{U} = \left(\rho,\ \rho u,\ \rho v,\ E\right)^T
$$
$$
\mathbf{F} = \begin{pmatrix}\rho u\\ \rho u^2 + p\\ \rho u v\\ u(E+p)\end{pmatrix}, \qquad
\mathbf{G} = \begin{pmatrix}\rho v\\ \rho u v\\ \rho v^2 + p\\ v(E+p)\end{pmatrix}, \qquad
\mathbf{S} = \begin{pmatrix}0\\ 0\\ \rho g\\ \rho g v\end{pmatrix}
$$
Equation of state: $p = (\gamma-1)\left(E - \tfrac{1}{2}\rho(u^2+v^2)\right)$.

* **Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $\quad t \in [0, 3.0]$.

* **Boundary Conditions:** $x$: Periodic. $y=0$ and $y=1$: Reflective / free-slip walls (no-penetration $v=0$; mirror reflection of $\rho, u, p$).

* **Initial Conditions:**
$$
\rho(x,y,0) = 2.0 + (1.0 - 2.0)\cdot\frac{1}{2}\left[1 + \tanh\left(50\,(y - 0.5)\right)\right]
$$
$$
p(x,y,0) = \begin{cases} 2y + 1, & y < 0.5 \\ y + 1.5, & y \geq 0.5 \end{cases}
$$
$$
u(x,y,0) = 0
$$
$$
v(x,y,0) = -0.025\, c(x,y)\, \cos(8\pi x)\, \left[\sin(\pi y)\right]^6, \qquad c(x,y) = \sqrt{\frac{\gamma\, p(x,y,0)}{\rho(x,y,0)}}
$$
$$
E(x,y,0) = \frac{p(x,y,0)}{\gamma - 1} + \frac{1}{2}\,\rho(x,y,0)\, v(x,y,0)^2
$$

* **Constants & Parameters:** $\gamma = 1.4$; gravity magnitude $g = 1.0$ with $\mathbf{g} = [0, +1.0]^T$; $\rho_{heavy}=2.0$, $\rho_{light}=1.0$; interface at $y_0 = 0.5$; interface smoothing factor $50$; perturbation amplitude $0.025$; perturbation wavenumber $k = 8\pi$ (exactly one wavelength across the periodic $x$-extent).

* **Expected Physics:** Exponential linear growth of the single mode ($\sigma \approx \sqrt{Akg} \approx 2.9$ with $A = 1/3$) until $t \approx 0.7$–$1.0$; transition to nonlinear regime with bubbles of light fluid rising toward $y=0$ and spikes of heavy fluid sinking toward $y=1$; secondary Kelvin–Helmholtz roll-up along the shear layers; mixing zone spanning roughly $y \in [0.2, 0.8]$ by $t = 3.0$; weak shocks/acoustic transients from the small pressure–density imbalance inside the smoothed interface layer and from late-time jet impingement on the $y$-walls.

---

**2. Strategic Methodology**

* **Can we obtain an exact solution?** **No.** The Method of Characteristics yields closed-form solutions only for 1D simple-wave/Riemann-type problems. RTI is a genuinely multi-D instability: perturbed hydrostatic equilibrium with a contact discontinuity, exponential growth, secondary KH instabilities, and shock formation — no characteristic invariant can be integrated in closed form, and the dynamics are hydrodynamically unstable (no analytical ground truth exists).
* **Fourier Spectral:** Rejected — the $y$-direction has reflective walls (non-periodic), and the solution develops non-smooth features (contacts, shear layers, weak shocks) that destroy global spectral convergence.
* **Steady Continuous Galerkin:** Rejected — the problem is unsteady by design.
* **Selection:** **DGSEM in 2D plus time** — natively supports periodic $x$ / reflective $y$ boundaries, provides high-order accuracy for the smooth early phase, and offers local conservation with shock capturing and AMR for the late mixing phase.

```julia
# ## Problem Setup: Rayleigh–Taylor Instability
#
# A smoothed heavy-to-light density interface is initialized at y = 0.5.
# The piecewise pressure is hydrostatic away from the interface, and a
# single-mode vertical-velocity perturbation seeds the instability.
# Gravity acts in the positive y-direction.
#
# %%
@inline function initial_condition_rti(x, t, equations::CompressibleEulerEquations2D)
    x_coord, y = x

    # Heavy fluid (rho = 2) below the interface; light fluid (rho = 1) above.
    rho = 2.0 + (1.0 - 2.0) * 0.5 *
          (1.0 + tanh(50.0 * (y - 0.5)))

    p = y < 0.5 ? 2.0 * y + 1.0 : y + 1.5

    u = 0.0
    sound_speed = sqrt(equations.gamma * p / rho)
    v = -0.025 * sound_speed * cos(8.0 * pi * x_coord) *
        sin(pi * y)^6

    # prim2cons gives E = p/(gamma - 1) + rho*(u^2 + v^2)/2.
    return prim2cons(SVector(rho, u, v, p), equations)
end

@inline function source_terms_gravity(u, x, t,
                                      equations::CompressibleEulerEquations2D)
    g = 1.0
    rho, rho_v1, rho_v2, rho_e = u

    # rho_v2 = rho*v, so the final component is g*rho*v.
    return SVector(0.0, 0.0, g * rho, g * rho_v2)
end

# Conservative-state density used by the shock-capturing and AMR indicators.
@inline function density_indicator(u, equations)
    return u[1]
end
```

```julia
function condition_save_npz(u, t, integrator)
    index = next_npz_save_index[]
    return index <= length(npz_save_times) &&
           t >= npz_save_times[index] - 1.0e-10
end

function affect_save_npz(integrator)
    save_npz_file(integrator)

    # Advance past every schedule entry reached at this integrator time.
    while next_npz_save_index[] <= length(npz_save_times) &&
          integrator.t >= npz_save_times[next_npz_save_index[]] - 1.0e-10
        next_npz_save_index[] += 1
    end
    return nothing
end

    next_npz_save_index[] = 1
    affect_save_npz(integrator) # Save the initial state at t = 0.
```

**1. Problem Statement**

We solve the 2D inviscid, compressible Euler equations with a gravitational source for the single-mode Rayleigh–Taylor Instability (RTI). Heavy fluid ($\rho=2$) lies below light fluid ($\rho=1$) with gravity acting in $+y$ (from heavy into light) — a buoyantly unstable configuration. A single-wavelength vertical-velocity perturbation seeds the instability. Objective: a high-fidelity, standalone ground-truth dataset on $[0,0.25]\times[0,1]$ for $t\in[0,3]$, resolving linear growth, nonlinear spike/bubble formation, and Kelvin–Helmholtz roll-up — with the visualization defects of the previous trial eliminated.

---

**2. Mathematical Specification (Code-Ready Extraction)**

* **Governing Equations:** 2D Compressible Euler with gravity source ($\mathbf{g} = [0, g]^T$, $g=1.0$):
$$\partial_t \begin{pmatrix} \rho \\ \rho u \\ \rho v \\ \rho e \end{pmatrix} + \partial_x \begin{pmatrix} \rho u \\ \rho u^2 + p \\ \rho u v \\ u(\rho e + p) \end{pmatrix} + \partial_y \begin{pmatrix} \rho v \\ \rho u v \\ \rho v^2 + p \\ v(\rho e + p) \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ \rho g \\ \rho g v \end{pmatrix}$$
with equation of state $p = (\gamma - 1)\left(\rho e - \tfrac{1}{2}\rho(u^2 + v^2)\right)$.

* **Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $t \in [0, 3.0]$.

* **Boundary Conditions:**
  * $x = 0$ and $x = 0.25$: **Periodic**.
  * $y = 0$ and $y = 1$: **Reflective / free-slip walls** (no-penetration $v = 0$; slip in $u$).

* **Initial Conditions** (interface at $y = 0.5$):
$$\rho(x,y,0) = 2.0 + (1.0 - 2.0)\cdot\frac{1}{2}\left(1 + \tanh\left(50(y - 0.5)\right)\right)$$
$$p(x,y,0) = \begin{cases} 2y + 1, & y < 0.5 \\ y + 1.5, & y \geq 0.5 \end{cases}$$
$$u(x,y,0) = 0$$
$$v(x,y,0) = -0.025 \cdot c(x,y) \cdot \cos(8\pi x) \cdot \sin^6(\pi y), \qquad c(x,y) = \sqrt{\gamma\, p / \rho}$$
$$\rho e(x,y,0) = \frac{p}{\gamma - 1} + \frac{1}{2}\rho\, v^2$$

* **Constants & Parameters:** $\gamma = 1.4$; gravity vector $\mathbf{g} = [0, 1.0]^T$; $\rho_{heavy}=2.0$, $\rho_{light}=1.0$; interface $y_0 = 0.5$; tanh smoothing width $50$; perturbation amplitude $0.025$; perturbation wavenumber $8\pi$ (exactly one period across the domain width); $\mu = 0$, $k = 0$.

```julia
# ## Methodology: AMR-Aware Element-Patch Interpolation
# `PlotData2D` evaluates the DG polynomial on visualization nodes within
# each AMR element. This routine assembles those element patches on a fine
# uniform Cartesian grid instead of binning scattered points.

function _rti_barycentric_weights(nodes)
    weights = ones(Float64, length(nodes))
    for i in eachindex(nodes), j in eachindex(nodes)
        if i != j
            weights[i] /= nodes[i] - nodes[j]
        end
    end
    return weights
end

function _rti_barycentric_basis!(basis, nodes, weights, q)
    fill!(basis, 0.0)

    # Avoid a removable singularity when q coincides with a plot node.
    for k in eachindex(nodes)
        if q == nodes[k]
            basis[k] = 1.0
            return nothing
        end
    end

    denominator = 0.0
    for k in eachindex(nodes)
        basis[k] = weights[k] / (q - nodes[k])
        denominator += basis[k]
    end
    for k in eachindex(basis)
        basis[k] /= denominator
    end
    return nothing
end

function rasterize_data(x, y, z, nx=256, ny=1024)
    x_raw, y_raw = x, y
    xv = vec(Float64.(x))
    yv = vec(Float64.(y))
    zv = vec(Float64.(z))

    @assert length(xv) == length(yv) == length(zv)
    @assert all(isfinite, xv) && all(isfinite, yv) && all(isfinite, zv)

    # PlotData2D normally uses 2*polydeg visualization nodes per direction.
    # Infer the value as well for the array layouts used by Trixi/NPZ.
    nvis = 2 * polydeg
    if ndims(x_raw) == 3
        nvis = size(x_raw, 1)
    elseif ndims(x_raw) == 2
        if isqrt(size(x_raw, 1))^2 == size(x_raw, 1)
            nvis = isqrt(size(x_raw, 1))
        elseif size(x_raw, 1) <= 32
            nvis = size(x_raw, 1)
        end
    elseif ndims(x_raw) == 1
        nvis = 0
        for candidate in (2 * polydeg, 2 * polydeg + 1, polydeg + 1)
            block_size = candidate^2
            if length(xv) % block_size == 0
                xtest = unique(round.(view(xv, 1:block_size), digits=14))
                ytest = unique(round.(view(yv, 1:block_size), digits=14))
                if length(xtest) == candidate && length(ytest) == candidate
                    nvis = candidate
                    break
                end
            end
        end
        nvis > 0 || error("Unable to infer the PlotData2D element-patch size.")
    end

    block_size = nvis^2
    length(xv) % block_size == 0 ||
        error("PlotData2D data do not contain complete element patches.")
    nblocks = length(xv) ÷ block_size

    x_min, x_max = 0.0, 0.25
    y_min, y_max = 0.0, 1.0
    x_grid = collect(range(x_min, x_max; length=nx))
    y_grid = collect(range(y_min, y_max; length=ny))

    values_sum = zeros(Float64, ny, nx)
    values_count = zeros(Int, ny, nx)

    for block in 0:(nblocks - 1)
        indices = (block * block_size + 1):((block + 1) * block_size)
        xb = view(xv, indices)
        yb = view(yv, indices)
        zb = view(zv, indices)

        # Rounding only groups repeated patch coordinates; the solution
        # values themselves are never rounded or regularized.
        xkeys = round.(xb, digits=14)
        ykeys = round.(yb, digits=14)
        xs = sort(unique(xkeys))
        ys = sort(unique(ykeys))

        length(xs) == nvis && length(ys) == nvis ||
            error("Unexpected non-tensor-product PlotData2D element patch.")

        patch = Matrix{Float64}(undef, nvis, nvis) # [y-index, x-index]
        for k in 1:block_size
            ix = searchsortedfirst(xs, xkeys[k])
            iy = searchsortedfirst(ys, ykeys[k])
            patch[iy, ix] = zb[k]
        end

        weights_x = _rti_barycentric_weights(xs)
        weights_y = _rti_barycentric_weights(ys)
        basis_x = Vector{Float64}(undef, nvis)
        basis_y = Vector{Float64}(undef, nvis)

        i_first = max(1, searchsortedfirst(x_grid, xs[1]))
        i_last = min(nx, searchsortedlast(x_grid, xs[end]))
        j_first = max(1, searchsortedfirst(y_grid, ys[1]))
        j_last = min(ny, searchsortedlast(y_grid, ys[end]))

        if i_first <= i_last && j_first <= j_last
            for j in j_first:j_last, i in i_first:i_last
                _rti_barycentric_basis!(basis_x, xs, weights_x, x_grid[i])
                _rti_barycentric_basis!(basis_y, ys, weights_y, y_grid[j])

                value = 0.0
                for jj in 1:nvis, ii in 1:nvis
                    value += basis_y[jj] * patch[jj, ii] * basis_x[ii]
                end

                # Overlaps occur only at shared element boundaries. Averaging
                # them avoids seams without drawing element-edge lines.
                values_sum[j, i] += value
                values_count[j, i] += 1
            end
        end
    end

    grid = Matrix{Float64}(undef, ny, nx)
    for j in 1:ny, i in 1:nx
        if values_count[j, i] > 0
            grid[j, i] = values_sum[j, i] / values_count[j, i]
        else
            # This is only a roundoff/boundary fallback. Every pixel is filled,
            # so heatmap rendering cannot produce transparent rows or bands.
            best_index = 1
            best_distance = Inf
            for k in eachindex(xv)
                distance = ((xv[k] - x_grid[i]) / (x_max - x_min))^2 +
                           ((yv[k] - y_grid[j]) / (y_max - y_min))^2
                if distance < best_distance
                    best_distance = distance
                    best_index = k
                end
            end
            grid[j, i] = zv[best_index]
        end
    end

    all(isfinite, grid) || error("Non-finite value in interpolated plot grid.")
    return grid
end
```

```julia
# ## Methodology: AMR-Aware Element-Patch Interpolation
# `PlotData2D` evaluates the DG polynomial on visualization nodes within
# each AMR element. Element views are determined from the actual array
# dimensions and validated before tensor-product interpolation. A scattered
# fallback handles layout-free data without leaving unfilled grid cells.

function _rti_barycentric_weights(nodes)
    weights = ones(Float64, length(nodes))
    for i in eachindex(nodes), j in eachindex(nodes)
        if i != j
            weights[i] /= nodes[i] - nodes[j]
        end
    end
    return weights
end

function _rti_barycentric_basis!(basis, nodes, weights, q)
    fill!(basis, 0.0)

    for k in eachindex(nodes)
        if q == nodes[k]
            basis[k] = 1.0
            return nothing
        end
    end

    denominator = 0.0
    for k in eachindex(nodes)
        basis[k] = weights[k] / (q - nodes[k])
        denominator += basis[k]
    end
    for k in eachindex(basis)
        basis[k] /= denominator
    end
    return nothing
end

# Return one element without flattening the complete PlotData2D arrays.
function _rti_patch_view(a, layout, nvis, element)
    if layout === :elements_last
        return view(a, :, :, element)
    elseif layout === :elements_first
        return view(a, element, :, :)
    elseif layout === :elements_middle
        return view(a, :, element, :)
    elseif layout === :element_columns
        return view(a, :, element)
    elseif layout === :element_rows
        return view(a, element, :)
    elseif layout === :columns_contiguous
        columns = ((element - 1) * nvis + 1):(element * nvis)
        return view(a, :, columns)
    elseif layout === :rows_contiguous
        rows = ((element - 1) * nvis + 1):(element * nvis)
        return view(a, rows, :)
    elseif layout === :columns_interleaved
        nelements = size(a, 2) ÷ nvis
        columns = element:nelements:(nvis * nelements)
        return view(a, :, columns)
    elseif layout === :rows_interleaved
        nelements = size(a, 1) ÷ nvis
        rows = element:nelements:(nvis * nelements)
        return view(a, rows, :)
    end
    error("Unknown PlotData2D element layout: $layout")
end

function _rti_layout_candidates(a)
    candidates = Tuple{Symbol, Int, Int}[]

    if ndims(a) == 3
        s = size(a)
        if s[1] == s[2] && s[1] > 1
            push!(candidates, (:elements_last, s[1], s[3]))
        end
        if s[2] == s[3] && s[2] > 1
            push!(candidates, (:elements_first, s[2], s[1]))
        end
        if s[1] == s[3] && s[1] > 1
            push!(candidates, (:elements_middle, s[1], s[2]))
        end
    elseif ndims(a) == 2
        s1, s2 = size(a)

        # Horizontally concatenated nvis-by-nvis element patches.
        if s1 >= 2 && s1 <= 64 && s2 % s1 == 0
            nelements = s2 ÷ s1
            push!(candidates, (:columns_contiguous, s1, nelements))
            push!(candidates, (:columns_interleaved, s1, nelements))
        end

        # Vertically concatenated nvis-by-nvis element patches.
        if s2 >= 2 && s2 <= 64 && s1 % s2 == 0
            nelements = s1 ÷ s2
            push!(candidates, (:rows_contiguous, s2, nelements))
            push!(candidates, (:rows_interleaved, s2, nelements))
        end

        # One flattened element per column or per row.
        nvis = isqrt(s1)
        if nvis > 1 && nvis * nvis == s1
            push!(candidates, (:element_columns, nvis, s2))
        end
        nvis = isqrt(s2)
        if nvis > 1 && nvis * nvis == s2
            push!(candidates, (:element_rows, nvis, s1))
        end
    end

    return unique(candidates)
end

# Convert one element view to sorted tensor-product nodes and a [y, x] patch.
# Returning `nothing` rejects an incorrect element slicing without throwing.
function _rti_tensor_patch(xb, yb, zb, nvis)
    xv = vec(Float64.(xb))
    yv = vec(Float64.(yb))
    zv = vec(Float64.(zb))

    length(xv) == nvis * nvis || return nothing
    length(yv) == length(xv) && length(zv) == length(xv) || return nothing

    xkeys = round.(xv, digits=14)
    ykeys = round.(yv, digits=14)
    xs = sort(unique(xkeys))
    ys = sort(unique(ykeys))

    length(xs) == nvis && length(ys) == nvis || return nothing

    patch = fill(NaN, nvis, nvis)
    for k in eachindex(xv)
        ix = searchsortedfirst(xs, xkeys[k])
        iy = searchsortedfirst(ys, ykeys[k])
        ix <= nvis && iy <= nvis || return nothing
        patch[iy, ix] = zv[k]
    end

    # Missing tensor-product combinations remain NaN. This also rejects
    # duplicate coordinate assignments and non-finite solution values.
    all(isfinite, patch) || return nothing
    return xs, ys, patch
end

function _rti_layout_is_valid(x, y, z, layout, nvis, nelements)
    for element in 1:nelements
        xb = _rti_patch_view(x, layout, nvis, element)
        yb = _rti_patch_view(y, layout, nvis, element)
        zb = _rti_patch_view(z, layout, nvis, element)
        if _rti_tensor_patch(xb, yb, zb, nvis) === nothing
            return false
        end
    end
    return true
end

# Layout-free fallback for scattered/triangulated PlotData2D output. Spatial
# bins avoid an O(number_of_pixels * number_of_samples) nearest-neighbor scan.
function _rti_scattered_raster(xv, yv, zv, x_grid, y_grid)
    nx = length(x_grid)
    ny = length(y_grid)
    x_min, x_max = extrema(x_grid)
    y_min, y_max = extrema(y_grid)

    bins = [Int[] for j in 1:ny, i in 1:nx]
    for k in eachindex(xv)
        i = clamp(floor(Int, (xv[k] - x_min) / (x_max - x_min) * nx) + 1,
                  1, nx)
        j = clamp(floor(Int, (yv[k] - y_min) / (y_max - y_min) * ny) + 1,
                  1, ny)
        push!(bins[j, i], k)
    end

    grid = Matrix{Float64}(undef, ny, nx)
    neighbors = Int[]
    max_radius = max(nx, ny)

    for j in 1:ny, i in 1:nx
        empty!(neighbors)

        # Add only the new square ring at each radius, so samples are never
        # duplicated. Twelve samples give a local interpolation stencil.
        for radius in 0:max_radius
            j_lo, j_hi = max(1, j - radius), min(ny, j + radius)
            i_lo, i_hi = max(1, i - radius), min(nx, i + radius)
            for jj in j_lo:j_hi, ii in i_lo:i_hi
                if max(abs(jj - j), abs(ii - i)) == radius
                    append!(neighbors, bins[jj, ii])
                end
            end
            if length(neighbors) >= 12
                break
            end
        end

        isempty(neighbors) && error("No scattered samples available for interpolation.")

        weighted_sum = 0.0
        weight_sum = 0.0
        exact_sum = 0.0
        exact_count = 0

        for k in neighbors
            dx = (xv[k] - x_grid[i]) / (x_max - x_min)
            dy = (yv[k] - y_grid[j]) / (y_max - y_min)
            distance_squared = dx * dx + dy * dy

            if distance_squared <= 1.0e-30
                # Average duplicate DG values at shared element boundaries.
                exact_sum += zv[k]
                exact_count += 1
            else
                weight = 1.0 / distance_squared
                weighted_sum += weight * zv[k]
                weight_sum += weight
            end
        end

        if exact_count > 0
            grid[j, i] = exact_sum / exact_count
        else
            weight_sum > 0.0 || error("Degenerate scattered interpolation stencil.")
            grid[j, i] = weighted_sum / weight_sum
        end
    end

    return grid
end

function rasterize_data(x, y, z, nx=256, ny=1024)
    if !(size(x) == size(y) && size(x) == size(z))
        error("PlotData2D coordinate and field arrays must have identical dimensions.")
    end
    if nx < 2 || ny < 2
        error("The rasterization grid must have at least two nodes per direction.")
    end

    xv = vec(Float64.(x))
    yv = vec(Float64.(y))
    zv = vec(Float64.(z))

    isempty(xv) && error("Cannot rasterize an empty PlotData2D array.")
    length(xv) == length(yv) && length(xv) == length(zv) ||
        error("PlotData2D coordinate and field lengths do not match.")
    if !(all(isfinite, xv) && all(isfinite, yv) && all(isfinite, zv))
        error("Non-finite coordinate or field value in PlotData2D input.")
    end

    x_min, x_max = 0.0, 0.25
    y_min, y_max = 0.0, 1.0
    x_grid = collect(range(x_min, x_max; length=nx))
    y_grid = collect(range(y_min, y_max; length=ny))

    # A candidate is accepted only after every element has been verified as
    # a complete tensor-product patch. No consecutive-block layout is assumed.
    selected = nothing
    for candidate in _rti_layout_candidates(x)
        layout, nvis, nelements = candidate
        if _rti_layout_is_valid(x, y, z, layout, nvis, nelements)
            selected = candidate
            break
        end
    end

    if selected === nothing
        grid = _rti_scattered_raster(xv, yv, zv, x_grid, y_grid)
        all(isfinite, grid) || error("Non-finite value in scattered plot grid.")
        return grid
    end

    layout, nvis, nelements = selected
    values_sum = zeros(Float64, ny, nx)
    values_count = zeros(Int, ny, nx)

    for element in 1:nelements
        xb = _rti_patch_view(x, layout, nvis, element)
        yb = _rti_patch_view(y, layout, nvis, element)
        zb = _rti_patch_view(z, layout, nvis, element)
        patch_data = _rti_tensor_patch(xb, yb, zb, nvis)
        patch_data === nothing &&
            error("PlotData2D element layout failed after validation.")
        xs, ys, patch = patch_data

        weights_x = _rti_barycentric_weights(xs)
        weights_y = _rti_barycentric_weights(ys)
        basis_x = Vector{Float64}(undef, nvis)
        basis_y = Vector{Float64}(undef, nvis)

        i_first = max(1, searchsortedfirst(x_grid, xs[1]))
        i_last = min(nx, searchsortedlast(x_grid, xs[end]))
        j_first = max(1, searchsortedfirst(y_grid, ys[1]))
        j_last = min(ny, searchsortedlast(y_grid, ys[end]))

        if i_first <= i_last && j_first <= j_last
            for j in j_first:j_last, i in i_first:i_last
                _rti_barycentric_basis!(basis_x, xs, weights_x, x_grid[i])
                _rti_barycentric_basis!(basis_y, ys, weights_y, y_grid[j])

                value = 0.0
                for jj in 1:nvis, ii in 1:nvis
                    value += basis_y[jj] * patch[jj, ii] * basis_x[ii]
                end

                # Shared element faces and corners are averaged, avoiding
                # visible seams without drawing any element-edge lines.
                values_sum[j, i] += value
                values_count[j, i] += 1
            end
        end
    end

    grid = Matrix{Float64}(undef, ny, nx)
    for j in 1:ny, i in 1:nx
        if values_count[j, i] > 0
            grid[j, i] = values_sum[j, i] / values_count[j, i]
        else
            # Roundoff/boundary fallback: every pixel must receive a value.
            best_index = 1
            best_distance = Inf
            for k in eachindex(xv)
                distance = ((xv[k] - x_grid[i]) / (x_max - x_min))^2 +
                           ((yv[k] - y_grid[j]) / (y_max - y_min))^2
                if distance < best_distance
                    best_distance = distance
                    best_index = k
                end
            end
            grid[j, i] = zv[best_index]
        end
    end

    all(isfinite, grid) || error("Non-finite value in interpolated plot grid.")
    return grid
end
```

**1. Problem Statement**

**1. Mathematical Specification (Code-Ready Extraction)**

* **Governing Equations:** 2D Compressible Euler with gravity ($\gamma = 1.4$):
$$
\frac{\partial}{\partial t}\begin{pmatrix}\rho\\ \rho u\\ \rho v\\ E\end{pmatrix}
+ \frac{\partial}{\partial x}\begin{pmatrix}\rho u\\ \rho u^2 + p\\ \rho u v\\ u(E+p)\end{pmatrix}
+ \frac{\partial}{\partial y}\begin{pmatrix}\rho v\\ \rho u v\\ \rho v^2 + p\\ v(E+p)\end{pmatrix}
= \begin{pmatrix}0\\ 0\\ \rho g\\ \rho g\, v\end{pmatrix},
\qquad
p = (\gamma-1)\left(E - \tfrac{1}{2}\rho(u^2+v^2)\right)
$$

* **Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $\quad t \in [0, 3.0]$

$$

$$
$$
p(x,y) = \begin{cases} 2y + 1, & y < 0.5 \\ y + 1.5, & y \geq 0.5 \end{cases}
$$
$$
u(x,y) = 0
$$
$$
v(x,y) = -0.025\, c(x,y)\,\cos(8\pi x)\,\left[\sin(\pi y)\right]^6,
\qquad c(x,y) = \sqrt{\frac{\gamma\, p(x,y)}{\rho(x,y)}}
$$
$$
E(x,y) = \frac{p}{\gamma - 1} + \frac{1}{2}\rho\left(u^2 + v^2\right)
$$

```julia
    inverse_jacobian = cache.elements.inverse_jacobian

    # available directly. Quadrature weights include each element's Jacobian.
    for element in axes(u, 4), j in axes(u, 3), i in axes(u, 2)

        primitive = cons2prim(u_node, equations)

        v = primitive[3]
```

**1. Mathematical Specification (Code-Ready Extraction)**

* **Governing Equations:** 2D Compressible Euler with gravitational source:
$$\partial_t \begin{pmatrix} \rho \\ \rho u \\ \rho v \\ E \end{pmatrix} + \partial_x \begin{pmatrix} \rho u \\ \rho u^2 + p \\ \rho u v \\ u(E+p) \end{pmatrix} + \partial_y \begin{pmatrix} \rho v \\ \rho u v \\ \rho v^2 + p \\ v(E+p) \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ \rho g \\ \rho g v \end{pmatrix}, \qquad E = \frac{p}{\gamma - 1} + \frac{1}{2}\rho(u^2 + v^2)$$

* **Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $t \in [0, 3.0]$

* **Boundary Conditions:** $x$: Periodic. $y=0$ and $y=1$: Reflective / free-slip walls (no-penetration $v = 0$; tangential velocity, $\rho$, $p$ mirrored).

* **Initial Conditions** (exact, every field):
$$\rho(x,y) = 2.0 + (1.0 - 2.0)\cdot \frac{1}{2}\left(1 + \tanh\left(50(y - 0.5)\right)\right)$$
$$p(x,y) = \begin{cases} 2y + 1 & \text{if } y < 0.5 \\ y + 1.5 & \text{if } y \geq 0.5 \end{cases}$$
$$u(x,y) = 0$$
$$v(x,y) = -0.025 \cdot \sqrt{\frac{\gamma p}{\rho}} \cdot \cos(8\pi x) \cdot \sin^6(\pi y)$$
$$E(x,y) = \frac{p}{\gamma - 1} + \frac{1}{2}\rho\, v(x,y)^2$$

* **Constants & Parameters:** $\gamma = 1.4$; gravity $\mathbf{g} = [0, 1.0]^T$ (source adds momentum in $+y$); $\rho_{heavy} = 2.0$, $\rho_{light} = 1.0$; interface at $y = 0.5$; local sound speed $c = \sqrt{\gamma p / \rho}$; $\mu = 0$, $k = 0$.

**1. Problem Statement**

We solve the 2D inviscid compressible Euler equations with a gravity source for the single-mode Rayleigh–Taylor Instability: a heavy fluid ($\rho=2$) lies below a light fluid ($\rho=1$) with gravity $g=1.0$ acting in $+y$, making the interface Atwood-unstable ($A=1/3$). The prior trial produced visually correct RTI morphology but reported a 42% mass drift and 55% modified-energy drift — physically impossible for this configuration and diagnosed by the Advisor as a **diagnostic artifact** (unweighted nodal sums / rasterized data / inconsistent baseline vs. initial AMR). This trial's objective: regenerate the ground truth from scratch with **conservation-consistent quadrature diagnostics** and less aggressive AMR, targeting mass drift $\le 10^{-8}$ and modified-energy drift $\le 10^{-3}$.

---

**1. Mathematical Specification (Code-Ready Extraction)**

* **Governing Equations:** 2D Compressible Euler with gravity source:
$$\partial_t \mathbf{U} + \partial_x \mathbf{F}(\mathbf{U}) + \partial_y \mathbf{G}(\mathbf{U}) = \mathbf{S}(\mathbf{U})$$
$$\mathbf{U} = \begin{pmatrix}\rho \\ \rho u \\ \rho v \\ E\end{pmatrix},\quad \mathbf{F} = \begin{pmatrix}\rho u \\ \rho u^2 + p \\ \rho u v \\ u(E+p)\end{pmatrix},\quad \mathbf{G} = \begin{pmatrix}\rho v \\ \rho u v \\ \rho v^2 + p \\ v(E+p)\end{pmatrix},\quad \mathbf{S} = \begin{pmatrix}0 \\ 0 \\ \rho g \\ \rho g v\end{pmatrix}$$
Equation of state: $p = (\gamma - 1)\left(E - \tfrac{1}{2}\rho(u^2 + v^2)\right)$.

* **Domain:** $(x,y) \in [0, 0.25] \times [0, 1.0]$, $t \in [0, 3.0]$.

* **Boundary Conditions:** $x$: Periodic. $y=0$ and $y=1$: Reflective / free-slip walls (no-penetration $v=0$; zero mass flux by construction).

* **Initial Conditions** (every field, exact):
$$\rho(x,y,0) = 2.0 + (1.0 - 2.0)\cdot\tfrac{1}{2}\left(1 + \tanh\left(50(y - 0.5)\right)\right)$$
$$p(x,y,0) = \begin{cases} 2y + 1 & \text{if } y < 0.5 \\ y + 1.5 & \text{if } y \geq 0.5 \end{cases}$$
$$u(x,y,0) = 0$$
$$v(x,y,0) = -0.025 \cdot c(x,y) \cdot \cos(8\pi x) \cdot \sin^6(\pi y), \qquad c = \sqrt{\gamma p / \rho}$$
$$E(x,y,0) = \frac{p}{\gamma - 1} + \frac{1}{2}\rho\left(u^2 + v^2\right)$$

* **Constants & Parameters:** $\gamma = 1.4$; gravity $\mathbf{g} = [0, 1.0]^T$ (source adds momentum in $+y$); $\mu = 0$, $k = 0$; $\rho_{heavy}=2.0$, $\rho_{light}=1.0$; interface at $y=0.5$; smoothing factor $50$; perturbation amplitude $0.025$; mode wavenumber $8\pi$; $t_{end}=3.0$; snapshot interval $\Delta t_{save} = 0.1$.

* **Expected Physics:** Well-balanced hydrostatic start (perturbation only in $v$). Linear RT growth → nonlinear single-mode evolution: central heavy spike rises ($+y$), light bubbles descend at the domain edges; mushroom cap with rolled KH shear layers by $t \approx 2.25$; elongated filaments and secondary Kelvin–Helmholtz structures by $t = 3.0$. **Exact invariants** (no mass source, impermeable walls, periodic $x$): $M = \int_\Omega \rho\, dA = \text{const}$ and modified energy $\mathcal{E}^* = \int_\Omega (E - \rho y)\, dA = \text{const}$.

**2. Strategic Methodology**

* **Exact solution feasibility: NO.** The system is 2D, nonlinear, and multi-dimensional with a source term. The Method of Characteristics applies only to 1D (or quasi-1D) hyperbolic systems; here characteristic manifolds intersect and the solution becomes multi-valued with no closed-form entropy branch. The RTI evolution involves vortex rollup, secondary KH instabilities, and filament breakup — no separation-of-variables, Green's function, or MoC construction exists. Only the *unperturbed* hydrostatic state is an exact steady solution; the perturbed evolution is not. The Advisor explicitly confirms: no exact-method override is warranted.
* **Selection: Discontinuous Galerkin Spectral Element Method in 2D plus time (DGSEM).** It is conservative to machine precision (when integrals use proper Jacobian-weighted quadrature — the core fix of this trial), high-order for filament resolution, AMR-capable for the multi-scale interface, and pairs with shock capturing for the KH/shear layers.

```julia
# Integrate the mass component of the actual numerical wall flux. The
# slip-wall boundary function is evaluated with the same surface flux as the
# DG solver, rather than inferring a boundary flux from interior rho*v.
function _rti_wall_mass_flux(integrator, u, equations, solver, cache)
    weights = solver.basis.weights
    coordinates = cache.elements.node_coordinates
    nnodes = size(u, 2)
    tolerance = 1.0e-12

    flux_y0 = 0.0
    flux_y1 = 0.0
    abs_flux_y0 = 0.0
    abs_flux_y1 = 0.0
    flux_finite = true

    for element in axes(u, 4), face in (1, size(u, 3))
        y_face = coordinates[2, 1, face, element]
        if abs(y_face) <= tolerance
            wall_y = 0.0
        elseif abs(y_face - 1.0) <= tolerance
            wall_y = 1.0
        else
            continue
        end

        # Confirm that the complete element face, not just its first node,
        # coincides with the physical wall.
        all(abs(coordinates[2, i, face, element] - wall_y) <= tolerance
            for i in axes(u, 2)) || continue

        normal = wall_y == 0.0 ? SVector(0.0, -1.0) : SVector(0.0, 1.0)
        surface_jacobian =
            abs(coordinates[1, nnodes, face, element] -
                coordinates[1, 1, face, element]) / 2.0

        for i in axes(u, 2)
            u_node = Trixi.get_node_vars(u, equations, solver,
                                         i, face, element)
            x_node = coordinates[1, i, face, element]
            numerical_flux = boundary_condition_slip_wall(
                u_node, normal, SVector(x_node, wall_y), integrator.t,
                solver.surface_flux, equations)

            flux_finite = flux_finite && all(isfinite, numerical_flux)
            quadrature_weight = weights[i] * surface_jacobian
            mass_flux = numerical_flux[1]

            if wall_y == 0.0
                flux_y0 += quadrature_weight * mass_flux
                abs_flux_y0 += quadrature_weight * abs(mass_flux)
            else
                flux_y1 += quadrature_weight * mass_flux
                abs_flux_y1 += quadrature_weight * abs(mass_flux)
            end
        end
    end

    return (y0=flux_y0, y1=flux_y1,
            abs_y0=abs_flux_y0, abs_y1=abs_flux_y1,
            finite=flux_finite)
end

function _rti_current_mesh_diagnostics(integrator)
    semi = integrator.p
    _, equations, solver, cache = Trixi.mesh_equations_solver_cache(semi)
    u = Trixi.wrap_array(integrator.u, semi)
    weights = solver.basis.weights
    node_coordinates = cache.elements.node_coordinates
    inverse_jacobian = cache.elements.inverse_jacobian

    state_finite = all(isfinite, integrator.u)
    derived_fields_finite = true
    rho_min, rho_max = Inf, -Inf
    p_min, p_max = Inf, -Inf
    mass = 0.0
    modified_energy = 0.0

    # For this mesh, J_element = 1 / inverse_jacobian[element]. Thus every
    # volume integral uses omega_i*omega_j*J on the current AMR mesh.
    for element in axes(u, 4), j in axes(u, 3), i in axes(u, 2)
        u_node = Trixi.get_node_vars(u, equations, solver, i, j, element)
        primitive = cons2prim(u_node, equations)
        rho = primitive[1]
        p = primitive[4]
        y = node_coordinates[2, i, j, element]

        derived_fields_finite = derived_fields_finite &&
                                all(isfinite, primitive) &&
                                isfinite(u_node[4])
        rho_min = min(rho_min, rho)
        rho_max = max(rho_max, rho)
        p_min = min(p_min, p)
        p_max = max(p_max, p)

        quadrature_weight = weights[i] * weights[j] /
                            inverse_jacobian[element]
        mass += quadrature_weight * rho
        modified_energy += quadrature_weight * (u_node[4] - rho * y)
    end

    wall = _rti_wall_mass_flux(integrator, u, equations, solver, cache)
    all_fields_finite = state_finite && derived_fields_finite &&
                        wall.finite && isfinite(mass) &&
                        isfinite(modified_energy)
    positivity = rho_min > 0.0 && p_min > 0.0

    return (mass=mass,
            modified_energy=modified_energy,
            state_finite=state_finite,
            derived_fields_finite=derived_fields_finite,
            all_fields_finite=all_fields_finite,
            positivity=positivity,
            rho_min=rho_min, rho_max=rho_max,
            p_min=p_min, p_max=p_max,
            element_count=size(u, 4),
            wall_flux_y0=wall.y0, wall_flux_y1=wall.y1,
            wall_abs_flux_y0=wall.abs_y0,
            wall_abs_flux_y1=wall.abs_y1)
end

function _rti_update_diagnostic_state!(d)
    all_fields_finite_throughout[] =
        all_fields_finite_throughout[] && d.all_fields_finite
    positivity_throughout[] = positivity_throughout[] && d.positivity

    if isfinite(d.rho_min)
        diagnostic_rho_min[] = min(diagnostic_rho_min[], d.rho_min)
    end
    if isfinite(d.rho_max)
        diagnostic_rho_max[] = max(diagnostic_rho_max[], d.rho_max)
    end
    if isfinite(d.p_min)
        diagnostic_p_min[] = min(diagnostic_p_min[], d.p_min)
    end
    if isfinite(d.p_max)
        diagnostic_p_max[] = max(diagnostic_p_max[], d.p_max)
    end
    return nothing
end

function _rti_drifts(d)
    if !baseline_ready[]
        return (mass_signed=NaN, mass_absolute=NaN, mass_relative=NaN,
                energy_signed=NaN, energy_absolute=NaN, energy_relative=NaN)
    end

    mass_signed = d.mass - initial_mass[]
    energy_signed = d.modified_energy - initial_modified_energy[]
    return (mass_signed=mass_signed,
            mass_absolute=abs(mass_signed),
            mass_relative=abs(mass_signed) /
                          max(abs(initial_mass[]), eps(Float64)),
            energy_signed=energy_signed,
            energy_absolute=abs(energy_signed),
            energy_relative=abs(energy_signed) /
                            max(abs(initial_modified_energy[]), eps(Float64)))
end

function _rti_report_diagnostics(integrator, label)
    d = _rti_current_mesh_diagnostics(integrator)
    _rti_update_diagnostic_state!(d)
    drift = _rti_drifts(d)

    println(Printf.@sprintf(
        "Diagnostics [%s] t=%.5f elements=%d: finite=%s, positivity=%s, rho=[%.8e, %.8e], p=[%.8e, %.8e]",
        label, integrator.t, d.element_count,
        string(d.all_fields_finite), string(d.positivity),
        d.rho_min, d.rho_max, d.p_min, d.p_max))

    if baseline_ready[]
        println(Printf.@sprintf(
            "  mass=%.16e signed=%.3e absolute=%.3e relative=%.3e; modified_energy=%.16e signed=%.3e absolute=%.3e relative=%.3e",
            d.mass, drift.mass_signed, drift.mass_absolute,
            drift.mass_relative, d.modified_energy, drift.energy_signed,
            drift.energy_absolute, drift.energy_relative))
    else
        println(Printf.@sprintf(
            "  mass=%.16e, modified_energy=%.16e; baseline pending post-initial AMR",
            d.mass, d.modified_energy))
    end

    println(Printf.@sprintf(
        "  numerical wall mass-flux integrals: y0 signed=%.3e abs=%.3e; y1 signed=%.3e abs=%.3e",
        d.wall_flux_y0, d.wall_abs_flux_y0,
        d.wall_flux_y1, d.wall_abs_flux_y1))
    return d
end

function _rti_set_baseline!(d)
    initial_mass[] = d.mass
    initial_modified_energy[] = d.modified_energy
    baseline_ready[] = true
    println(Printf.@sprintf(
        "Post-initial-AMR baseline: elements=%d, M0=%.16e, Estar0=%.16e",
        d.element_count, initial_mass[], initial_modified_energy[]))

function _rti_record_amr_event!(pre, post)
    amr_event_count[] += 1
    mass_jump = post.mass - pre.mass
    energy_jump = post.modified_energy - pre.modified_energy
    max_abs_amr_mass_jump[] =
        max(max_abs_amr_mass_jump[], abs(mass_jump))
    max_abs_amr_energy_jump[] =
        max(max_abs_amr_energy_jump[], abs(energy_jump))

    println(Printf.@sprintf(
        "AMR audit event=%d: elements %d -> %d, mass_jump=%.16e, modified_energy_jump=%.16e",
        amr_event_count[], pre.element_count, post.element_count,
        mass_jump, energy_jump))
    return nothing
end

function _rti_initialize_amr_with_audit(cb, u, t, integrator)
    _rti_reset_diagnostics!()
    pre = _rti_report_diagnostics(integrator, "AMR initial pre")

    # Call the original initializer with its original callback object because
    # Trixi accesses the AMR controller through cb.affect!.
    original_initialize = getproperty(amr_callback, :initialize)
    if original_initialize !== nothing
        original_initialize(amr_callback, u, t, integrator)
    end

    post = _rti_report_diagnostics(integrator, "AMR initial post")
    _rti_record_amr_event!(pre, post)
    _rti_set_baseline!(post)
    return nothing
end

function _rti_affect_amr_with_audit(integrator)
    pre = _rti_report_diagnostics(integrator, "AMR pre")
    getproperty(amr_callback, :affect!)(integrator)
    post = _rti_report_diagnostics(integrator, "AMR post")
    _rti_record_amr_event!(pre, post)

    # This fallback is relevant only if a Trixi version performs the initial
    # adaptation through affect! rather than through initialize.
    if !baseline_ready[] && integrator.t == 0.0
        _rti_set_baseline!(post)
    end
    return nothing
end

function _rti_threshold_crossings(y, profile, threshold)
    crossings = Float64[]
    for k in 1:(length(profile) - 1)
        left = profile[k] - threshold
        right = profile[k + 1] - threshold
        if left == 0.0
            push!(crossings, y[k])
        elseif left * right < 0.0
            push!(crossings,
                  y[k] - left * (y[k + 1] - y[k]) /
                  (profile[k + 1] - profile[k]))
        end
    end
    if profile[end] == threshold
        push!(crossings, y[end])
    end
    return crossings
end

# Construct an x-averaged density profile directly from the current DG state.
# This diagnostic does not feed any conservation integral or plotting raster.
function _rti_interface_thickness(integrator)
    semi = integrator.p
    _, equations, solver, cache = Trixi.mesh_equations_solver_cache(semi)
    u = Trixi.wrap_array(integrator.u, semi)
    weights = solver.basis.weights
    coordinates = cache.elements.node_coordinates

    nbins = 2048
    profile_sum = zeros(Float64, nbins)
    profile_weight = zeros(Float64, nbins)
    nnodes = size(u, 2)

    for element in axes(u, 4), j in axes(u, 3)
        # LGL weights sum to two, so division by two gives the element's
        # x-average at this vertical polynomial node.
        rho_x_average = 0.0
        for i in axes(u, 2)
            rho_x_average += weights[i] * u[1, i, j, element]
        end
        rho_x_average /= 2.0

        y = coordinates[2, 1, j, element]
        element_width =
            abs(coordinates[1, nnodes, j, element] -
                coordinates[1, 1, j, element])
        bin = clamp(floor(Int, y * nbins) + 1, 1, nbins)
        profile_sum[bin] += element_width * rho_x_average
        profile_weight[bin] += element_width
    end

    known = findall(weight -> weight > 0.0, profile_weight)
    isempty(known) && return NaN
    profile = zeros(Float64, nbins)
    for k in known
        profile[k] = profile_sum[k] / profile_weight[k]
    end

    # Fill empty bins by linear interpolation; extend endpoint values into
    # empty bins outside the sampled range.
    for k in 1:(first(known) - 1)
        profile[k] = profile[first(known)]
    end
    for n in 1:(length(known) - 1)
        left = known[n]
        right = known[n + 1]
        for k in (left + 1):(right - 1)
            fraction = (k - left) / (right - left)
            profile[k] = (1.0 - fraction) * profile[left] +
                         fraction * profile[right]
        end
    end
    for k in (last(known) + 1):nbins
        profile[k] = profile[last(known)]
    end

    all(isfinite, profile) || return NaN
    y_profile = (collect(1:nbins) .- 0.5) ./ nbins

    # rho_light=1 and Delta rho=1 give thresholds 1.1 and 1.9.
    crossings90 = _rti_threshold_crossings(y_profile, profile, 1.9)
    crossings10 = _rti_threshold_crossings(y_profile, profile, 1.1)
    (isempty(crossings90) || isempty(crossings10)) && return NaN

    # Outermost crossings also remain defined when the developed RTI profile
    # contains multiple mixed regions.
    return abs(maximum(crossings10) - minimum(crossings90))
end
```
