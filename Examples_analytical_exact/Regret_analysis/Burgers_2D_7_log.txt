**2. Strategic Methodology**

#### Method of Characteristics (MoC) Feasibility

The PDE can be recast in a form that reveals the characteristic structure. Define
\[
\xi = x + y,\quad \eta = x - y.
\]

Then
\[
\partial_x = \partial_\xi + \partial_\eta,\quad
\partial_y = \partial_\xi - \partial_\eta.
\]

Compute:
\[
u_x + u_y = (\partial_\xi u + \partial_\eta u) + (\partial_\xi u - \partial_\eta u)
= 2\,\partial_\xi u.
\]

Hence the PDE becomes
\[
u_t + u (u_x + u_y) = u_t + 2u\,u_\xi = 0.
\]

Crucially, there is **no** \(\eta\)-derivative: \(\eta\) is a passive parameter. So for each fixed \(\eta\), we have a **1D inviscid Burgers equation** in \(\xi\):

\[
\boxed{
u_t(\xi,\eta,t) + 2u(\xi,\eta,t)\,\partial_\xi u(\xi,\eta,t) = 0
}
\]

with 1D periodicity in \(\xi\) induced by the 2D periodic box.

Initial condition in \((\xi,\eta)\):

Original IC:
\[
u(x,y,0) = \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{x+y}{2}\right)
= \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{\xi}{2}\right),
\]
independent of \(\eta\). Denote
\[
u_0(\xi) = \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{\xi}{2}\right).
\]

For each fixed \(\eta\), the equation
\[
u_t + 2u u_\xi = 0
\]
has standard Burgers-type characteristics:

- Characteristic ODEs:
  \[
  \frac{d\xi}{dt} = 2u, \quad \frac{d\eta}{dt} = 0,\quad \frac{du}{dt} = 0.
  \]
- Along a characteristic, \(u\) is constant: \(u(t) = u_0(\xi_0)\).
- Characteristic curves in \(\xi\):
  \[
  \xi(t) = \xi_0 + 2u_0(\xi_0)\,t.
  \]

Thus the solution can be written implicitly as
\[
u(\xi,\eta,t) = u_0(\xi_0),
\]
where \(\xi_0\) satisfies
\[
\xi = \xi_0 + 2u_0(\xi_0)\,t
\quad\Longleftrightarrow\quad
\xi_0 = \xi - 2u_0(\xi_0)\,t.
\]

Because \(u_0(\xi_0)\) is explicitly known,
\[
u_0(\xi_0) = \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{\xi_0}{2}\right),
\]
the characteristic relation is
\[
\xi = \xi_0 + 2\left(\frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{\xi_0}{2}\right)\right)t
= \xi_0 + \frac{2}{3}t + \frac{4}{3} t \sin\!\left(\frac{\xi_0}{2}\right).
\]

For each time \(t\) and each spatial point \((x,y)\), we compute \(\xi = x + y\) and solve the **implicit scalar equation** for \(\xi_0\):

\[
\boxed{
\xi = \xi_0 + \frac{2}{3}t + \frac{4}{3} t \sin\!\left(\frac{\xi_0}{2}\right)
}
\]

Then
\[
\boxed{
u(x,y,t) = u(\xi,\eta,t) = u_0(\xi_0)
= \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{\xi_0}{2}\right).
}
\]

- \(\eta = x - y\) does not appear in the formula; solution depends only on \(\xi=x+y\), consistent with the symmetry of the initial data and PDE.

This is a **full Method of Characteristics solution** (implicit form). For small \(t\), the map \(\xi_0 \mapsto \xi\) is invertible and single-valued. After shock formation time, the mapping becomes multi-valued; the **entropy condition** selects the physically correct weak solution branch. """
    solve_moc_2d_scalar(xi_in, t)

Exact solution for the 2D scalar conservation law: u_t + u(u_x + u_y) = 0
Initial condition: u(x,y,0) = 1/3 + 2/3 * sin((x+y)/2)

Uses Method of Characteristics with Entropy-Consistent shock fitting (Equal Area Rule).
Operates on the characteristic coordinate ξ = x + y.
"""
function solve_moc_2d_scalar(xi_in, t)
    # Physics parameters derived in Strategy
    # u = alpha + beta * sin(xi/2)
    alpha = 1.0 / 3.0
    beta  = 2.0 / 3.0
    
    # Map to phase space theta = xi / 2
    # The problem is 4π-periodic in ξ, so 2π-periodic in θ.
    theta = collect(Float64, xi_in) ./ 2.0
    pi_val = π

    # 1. Calculate Shock Location in Phase Space
    # Shock forms at θ = π (inflection of sin) and moves with mean speed alpha
    theta_s = pi_val + alpha * t

    # 2. Handle Periodicity relative to Shock
    # Wrap theta to be within [theta_s - π, theta_s + π)
    # This ensures we correctly classify points as "Pre-shock" (Left) or "Post-shock" (Right)
    # regardless of how many times the domain has wrapped.
    theta_wrapped = @. mod(theta - theta_s + pi_val, 2.0 * pi_val) - pi_val + theta_s

    # 3. Split Domain relative to the Shock
    idx1 = theta_wrapped .<= theta_s # Left / Pre-shock / Expansion
    idx2 = theta_wrapped .> theta_s  # Right / Post-shock / Compression

    theta1 = theta_wrapped[idx1]
    theta2 = theta_wrapped[idx2]

    # Prepare output array
    vv = similar(theta)

    # 4. Solve for Left Side (Expansion Branch)
    if !isempty(theta1)
        # Transform to 0-mean frame
        theta_n = theta1 .- alpha * t
        # Solve implicit characteristic equation
        u_vals = map(x -> solve_characteristic_root(x, t, beta), theta_n)
        v = alpha .+ beta .* sin.(u_vals)
        vv[idx1] = v
    end

    # 5. Solve for Right Side (Compression Branch with Entropy Reflection)
    if !isempty(theta2)
        # Reflect coordinate across the shock to the expansion side
        theta2_flipped = reverse(2.0 * theta_s .- theta2)
        theta_n = theta2_flipped .- alpha * t
        
        # Solve root on the single-valued side
        u2_vals = map(x -> solve_characteristic_root(x, t, beta), theta_n)
        v2 = alpha .+ beta .* sin.(u2_vals)
        
        # Reflect value back: u - alpha = -(u_flipped - alpha)
        v2_final = reverse(2.0 * alpha .- v2)
        vv[idx2] = v2_final
    end

    return vv
end

"""
    solve_characteristic_root(x_target, t, beta)

Solves the implicit characteristic equation for the phase variable:
    x_target - x0 - beta * t * sin(x0) = 0
"""
function solve_characteristic_root(x_target, t, beta)
    # Use x_target as initial guess since for small t, x0 ≈ x_target
    f(x0) = x_target - x0 - beta * t * sin(x0)
    return find_zero(f, x_target, Order1()) 
end

Initial condition: u(x,y,0) = 1/3 + 2/3 * sin((x+y)/2)

Uses Method of Characteristics with Entropy-Consistent shock fitting (Equal Area Rule).
Operates on the characteristic coordinate ξ = x + y.
"""
function solve_moc_2d_scalar(xi_in, t)
    # Physics parameters derived in Strategy
    # u = alpha + beta * sin(xi/2)
    alpha = 1.0 / 3.0
    beta  = 2.0 / 3.0
    
    # Map to phase space theta = xi / 2
    # The problem is 4π-periodic in ξ, so 2π-periodic in θ.
    theta = collect(Float64, xi_in) ./ 2.0
    pi_val = π

    # 1. Calculate Shock Location in Phase Space
    # Shock forms at θ = π (inflection of sin) and moves with mean speed alpha
    theta_s = pi_val + alpha * t

    # 2. Handle Periodicity relative to Shock
    # Wrap theta to be within [theta_s - π, theta_s + π)
    # This ensures we correctly classify points as "Pre-shock" (Left) or "Post-shock" (Right)
    # regardless of how many times the domain has wrapped.
    theta_wrapped = @. mod(theta - theta_s + pi_val, 2.0 * pi_val) - pi_val + theta_s

    # 3. Split Domain relative to the Shock
    idx1 = theta_wrapped .<= theta_s # Left / Pre-shock / Expansion
    idx2 = theta_wrapped .> theta_s  # Right / Post-shock / Compression

    theta1 = theta_wrapped[idx1]
    theta2 = theta_wrapped[idx2]

    # Prepare output array
    vv = similar(theta)

    # 4. Solve for Left Side (Expansion Branch)
    if !isempty(theta1)
        # Transform to 0-mean frame
        theta_n = theta1 .- alpha * t
        # Solve implicit characteristic equation
        u_vals = map(x -> solve_characteristic_root(x, t, beta), theta_n)
        v = alpha .+ beta .* sin.(u_vals)
        vv[idx1] = v
    end

    # 5. Solve for Right Side (Compression Branch with Entropy Reflection)
    if !isempty(theta2)
        # Reflect coordinate across the shock to the expansion side
        theta2_flipped = reverse(2.0 * theta_s .- theta2)

        v2_final = reverse(2.0 * alpha .- v2)
        vv[idx2] = v2_final
    end

"""
    solve_characteristic_root(x_target, t, beta)

Solves the implicit characteristic equation for the phase variable:
    x_target - x0 - beta * t * sin(x0) = 0

Uses Bisection method with guaranteed bounds to ensure convergence.
"""
function solve_characteristic_root(x_target, t, beta)
    # Define the residual function
    f(x0) = x_target - x0 - beta * t * sin(x0)
    
    # Determine bounds for the root x0
    # From x0 = x_target - beta * t * sin(x0), and sin(x0) in [-1, 1]:
    # x0 must be in [x_target - beta*t, x_target + beta*t]
    # We add a small epsilon to ensure the sign change occurs strictly inside or at bounds
    delta = abs(beta * t) + 1e-8
    bracket = (x_target - delta, x_target + delta)
    
    # Use Bisection for guaranteed convergence
    return find_zero(f, bracket, Bisection()) 
end
