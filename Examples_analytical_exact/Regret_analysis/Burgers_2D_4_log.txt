\[

**2. Strategic Methodology**

**Method-of-Characteristics Feasibility**

We rewrite:
\[
u_t + u u_x + u u_y = 0.
\]

Interpret as a transport equation for \(u\) along characteristic curves \((x(t),y(t))\):
\[
\frac{dx}{dt} = u,\qquad \frac{dy}{dt} = u,\qquad \frac{du}{dt} = 0.
\]

Thus along a characteristic:
- \(u\) is **constant**: \(u(t) = u_0(x_0,y_0)\).
- Characteristic ODEs:
  \[
  x(t) = x_0 + u_0(x_0,y_0)\,t,\qquad
  y(t) = y_0 + u_0(x_0,y_0)\,t.
  \]

Equivalently, in terms of the “diagonal” coordinate \(s = x+y\):

- Along characteristics, \(s(t) = x(t)+y(t)\) satisfies:
  \[
  \frac{ds}{dt} = \frac{dx}{dt}+\frac{dy}{dt} = u + u = 2u.
  \]
- Since \(u\) is constant along a characteristic and equal to its initial value at \((x_0,y_0)\),
  \[
  u = u_0(x_0,y_0) = \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{s_0}{2}\right),
  \]
  where \(s_0 = x_0 + y_0\).

Then
\[
s(t) = s_0 + 2u\,t = s_0 + 2u_0(s_0)\,t,
\]
with
\[
u_0(s_0) = \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{s_0}{2}\right).
\]

This yields the **implicit characteristic mapping**:
\[
s = s_0 + 2t\left[\frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{s_0}{2}\right)\right].
\]

For any \((x,y,t)\), one has
\[
s = x+y,
\]
and we must solve the scalar implicit equation
\[
s = s_0 + 2t\left[\frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{s_0}{2}\right)\right]
\]
for \(s_0\) (modulo \(4\pi\) periodicity in \(s\)), then
\[
u(x,y,t) = u_0(s_0) = \frac{1}{3} + \frac{2}{3}\sin\!\left(\frac{s_0}{2}\right).
\]

- Before shock formation, the mapping \(s_0 \mapsto s\) is monotone and single-valued; there is a unique root \(s_0\).
- After shock formation, multiple \(s_0\) values may map to the same \(s\), reflecting crossing characteristics. Then we must enforce the **entropy condition** to select the physically admissible weak solution. This can be implemented as:
  - For each \((x,y,t)\), find all roots \(s_0\) in one period \([0,4\pi)\).
  - Use the entropy condition (Lax/Oleinik) to select the correct branch (which yields a shock where necessary).

Hence, the **Method of Characteristics (MoC)** is not only feasible but provides an exact (implicit) solution for all times, including the post-shock regime via entropy-consistent root selection.

# --- Physical Functions ---
u_initial(s) = 1.0/3.0 + 2.0/3.0 * sin(s/2.0)

# Integral of u0(s) for Lax-Oleinik potential
# \int (1/3 + 2/3 sin(s/2)) ds = s/3 - 4/3 cos(s/2)
u0_potential_integral(s) = s/3.0 - 4.0/3.0 * cos(s/2.0)

"""
    solve_moc_point(x, y, t)

Computes the exact entropy solution u(x,y,t) for the 2D scalar conservation law
using the Method of Characteristics on the diagonal s = x + y.
Handles shock formation via Lax-Oleinik potential minimization.
"""
function solve_moc_point(x, y, t)
    # 1. Diagonal coordinate
    s_target = x + y
    
    # 2. Early exit for t=0
    if t == 0.0
        return u_initial(s_target)
    end

    # 3. Define the characteristic relation
    # We need s0 such that: s0 + 2*t*u0(s0) = s_target (modulo 4π)
    # Since u \in [-1/3, 1], drift is limited. We check s_target and neighbors.
    period = 4.0 * π
    
    # Map s_target to fundamental period [0, 4π) for consistency
    s_base = mod(s_target, period)
    
    # Potential targets to check for wrapping characteristics
    # Max velocity is 1.0, max time is 2.0 -> max drift 2.0.
    # Domain is ~12.5. Wrapping is minimal but we check neighbors to be safe.
    targets = [s_base - period, s_base, s_base + period]
    
    best_s0 = NaN
    min_potential = Inf
    found_root = false

    # Grid for bracketing roots (coarse search)
    # 64 segments is sufficient for smooth sine waves
    n_brackets = 64
    ds = period / n_brackets
    
    for S_t in targets
        # Characteristic function: G(s0) = s0 + 2t*u0(s0) - S_t
        G(s0) = s0 + 2.0 * t * u_initial(s0) - S_t
        
        # Bracket and find roots in [0, 4π]
        for i in 1:n_brackets
            s_a = (i-1)*ds
            s_b = i*ds
            
            val_a = G(s_a)
            val_b = G(s_b)
            
            if val_a * val_b <= 0.0
                # Root exists in interval
                s0_root = find_zero(G, (s_a, s_b), Bisection())
                
                # Calculate Lax-Oleinik Potential
                # J(s0) = Integral(u0) + (S_t - s0)^2 / (4t)
                # Note: Flux f(u)=u^2 -> f'(u)=2u. Lax formula uses (x-y)^2/(2*f''(u)*t) ? 
                # For u_t + (u^2)_s = 0, f(u)=u^2. Legendre of f is v^2/4.
                # Potential = U0(y) + t * L((x-y)/t) = U0(y) + (x-y)^2 / (4t)
                pot = u0_potential_integral(s0_root) + (S_t - s0_root)^2 / (4.0 * t)
                
                if pot < min_potential
                    min_potential = pot
                    best_s0 = s0_root
                    found_root = true
                end
            end
        end
    end

    if !found_root
        # Fallback (should not happen with correct bracketing)
        return u_initial(s_target)
    end

    return u_initial(best_s0)
end
