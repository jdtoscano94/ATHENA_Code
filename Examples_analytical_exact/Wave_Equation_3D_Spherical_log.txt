**2. Strategic Methodology**

#### 2.1 Exact Reduction via Spherical Symmetry

Use the standard reduction for the 3D radial wave equation:
\[
v(r,t) := r\,u(r,t).
\]

Compute the equation for \(v\):

Start from
\[
u_{tt} = \frac{1}{r^2}\partial_r(r^2 u_r).
\]

With \(u = v/r\),
\[
u_r = \frac{v_r r - v}{r^2},
\]
\[
r^2 u_r = v_r r - v,
\]
\[
\partial_r(r^2 u_r) = \partial_r(v_r r - v) = v_{rr} r.
\]

Hence
\[
u_{tt} = \frac{1}{r^2}\, v_{rr} r = \frac{1}{r} v_{rr}.
\]

Left-hand side:
\[
u_{tt} = \frac{1}{r} v_{tt}.
\]

So for \(r>0\):
\[
\frac{1}{r} v_{tt} = \frac{1}{r} v_{rr}
\quad\Rightarrow\quad
\boxed{v_{tt} = v_{rr}}.
\]

Thus \(v(r,t)\) satisfies the **1D wave equation** on the interval \(r\in(0,10)\).

#### 2.2 Transformed Boundary & Initial Conditions

  u_r(10,t) = 0

  v_r(10,t) = v(10,t).

#### 2.3 Exact Solution Class

On \((0,10)\), \(v\) satisfies
\[
v_{tt} = v_{rr},\quad v(0,t)=0,\quad v_r(10,t) = \frac{1}{10}v(10,t),
\]
with \(v(r,0)=f(r)\), \(v_t(r,0)=0\), where \(f(r)=e^{-10(r-5)^2}\sin(\pi r/10)\).

This is a **linear, second-order hyperbolic PDE** on a finite interval with mixed (Dirichlet–Robin) homogeneous linear boundary conditions. It is ideally suited to separation of variables / eigenfunction expansion:

Seek eigenmodes
\[
v(r,t) = X(r)T(t),
\]
leading to
\[
\frac{T''(t)}{T(t)} = \frac{X''(r)}{X(r)} = -\lambda,
\]
with spatial problem
\[
X''(r) + \lambda X(r) = 0, \quad X(0)=0,\quad X'(10) = \frac{1}{10}X(10).
\]

- This yields a discrete set of eigenvalues \(\lambda_n = k_n^2 > 0\), with eigenfunctions
  \[
  X_n(r) = \sin(k_n r),
  \]
  where \(k_n\) satisfy
  \[
  X(0)=0 \Rightarrow X(r)=A\sin(k r),
  \]
  \[
  X'(10) = \frac{1}{10}X(10)
  \Rightarrow k\cos(10k) = \frac{1}{10}\sin(10k)
  \Rightarrow \tan(10k) = 10k.
  \]

- Time dependence:
  \[
  T_n(t) = A_n \cos(k_n t) + B_n \sin(k_n t).
  \]

- Imposing \(v_t(r,0)=0\) forces \(B_n=0\), so:
  \[
  v(r,t) = \sum_{n=1}^\infty a_n \cos(k_n t)\,X_n(r) = \sum_{n=1}^\infty a_n \cos(k_n t)\,\sin(k_n r).
  \]

- Coefficients from initial displacement \(f(r)\):
  \[
  f(r) = \sum_{n=1}^\infty a_n \sin(k_n r),
  \]
  with inner product appropriate to this Sturm–Liouville problem (weight \(w(r)=1\) here). So
  \[
  a_n = \frac{\displaystyle \int_0^{10} f(r)\,\sin(k_n r)\,dr}{\displaystyle \int_0^{10} \sin^2(k_n r)\,dr}.

\[
\boxed{
v(r,t) = \sum_{n=1}^\infty a_n \cos(k_n t)\,\sin(k_n r),\quad
k_n\ \text{solve}\ \tan(10k_n) = 10k_n,\quad

\]

Then
\[
\boxed{

= \frac{1}{r} \sum_{n=1}^\infty a_n \cos(k_n t)\,\sin(k_n r),
\quad r>0.
}

At \(r=0\), define \(u(0,t)\) via limit:
\[
u(0,t) = \lim_{r\to 0} \frac{v(r,t)}{r} = \sum_{n=1}^\infty a_n k_n \cos(k_n t),

This is an **exact analytical solution via separation of variables**, which is a special case of an analytical method and must be prioritized as the main method.

# ## Algorithm: Separation of Variables for Spherically Symmetric Wave Equation
# The function `solve_wave_spherical` computes the exact solution u(r,t) via eigenfunction expansion.
#
# ### Logic Flow:
# 1.  **Eigenvalue Problem**: Solves tan(10k) = 10k to find discrete wavenumbers k_n.
# 2.  **Spectral Decomposition**: Projects the initial condition v(r,0) onto the basis X_n(r) = sin(k_n r) to find coefficients a_n.
# 3.  **Series Summation**: Reconstructs v(r,t) and computes u(r,t) = v(r,t)/r.
# 4.  **Regularity**: Handles the removable singularity at r=0 via analytical limits.

using QuadGK

"""
    compute_eigenvalues(N_modes)

Finds the first N_modes positive roots of the characteristic equation:
    tan(10k) = 10k
Roots are located in intervals (n*pi/10, n*pi/10 + pi/20).
"""
function compute_eigenvalues(N_modes)
    k_vals = Float64[]
    for n in 1:N_modes
        # Bracket search for the n-th root
        # Asymptotes at pi/20 + n*pi/10. Roots are slightly to the left of asymptotes?
        # tan(x)=x intersects in (n*pi, n*pi + pi/2) for x=10k
        # So 10k in (n*pi, n*pi + pi/2) -> k in (n*pi/10, n*pi/10 + pi/20)
        lower = n * π / 10.0 + 1e-4
        upper = n * π / 10.0 + π / 20.0 - 1e-4
        
        f(k) = tan(10.0 * k) - 10.0 * k
        
        # Bisection is robust for bracketed roots
        k_root = find_zero(f, (lower, upper), Roots.Bisection())
        push!(k_vals, k_root)
    end
    return k_vals
end

"""
    compute_coefficients(k_vals)

Computes Fourier coefficients a_n for the initial condition v(r,0).
v(r,0) = e^{-10(r-5)^2} * sin(pi*r/10)
"""
function compute_coefficients(k_vals)
    a_vals = Float64[]
    
    # Initial condition function for v(r)
    # v(r,0) = r * u(r,0) = e^{-10(r-5)^2} * sin(pi*r/10)
    v0(r) = exp(-10.0 * (r - 5.0)^2) * sin(π * r / 10.0)
    
    for k in k_vals
        # Numerator: Integral of v0(r) * sin(k*r)
        integrand_num(r) = v0(r) * sin(k * r)
        num, _ = quadgk(integrand_num, 0.0, 10.0)
        
        # Denominator: Integral of sin^2(k*r)
        integrand_den(r) = sin(k * r)^2
        den, _ = quadgk(integrand_den, 0.0, 10.0)
        
        push!(a_vals, num / den)
    end
    return a_vals
end

"""
    solve_wave_spherical(r_in, t, k_vals, a_vals)

Computes the exact solution u(r,t) = (1/r) * sum(a_n * cos(k_n*t) * sin(k_n*r)).
Handles r=0 via limit: u(0,t) = sum(a_n * k_n * cos(k_n*t)).
"""
function solve_wave_spherical(r_in, t, k_vals, a_vals)
    r_points = collect(Float64, r_in)
    u_out = zeros(length(r_points))
    
    for (i, r) in enumerate(r_points)
        sum_v = 0.0
        if r > 1e-10
            # Standard formula for r > 0
            for (k, a) in zip(k_vals, a_vals)
                sum_v += a * cos(k * t) * sin(k * r)
            end
            u_out[i] = sum_v / r
        else
            # Limit at r -> 0
            for (k, a) in zip(k_vals, a_vals)
                sum_v += a * k * cos(k * t)
            end
            u_out[i] = sum_v
        end
    end
    return u_out
end
