## 1. Mathematical Specification (Code-Ready Extraction)

### Governing Equations
\[
\partial_t u(x,t) + u(x,t)\,\partial_x u(x,t) \;=\; \nu\,\partial_{xx}u(x,t),
\qquad (x,t)\in[-1,1]\times[0,1].
\]

### Domain
\[
x\in[-1,1],\qquad t\in[0,1].
\]

### Boundary Conditions
Periodic in \(x\):
\[
u(-1,t)=u(1,t),\qquad \partial_x u(-1,t)=\partial_x u(1,t)\quad \forall t\in[0,1].
\]

### Initial Conditions
\[
u(x,0) = -\sin(\pi x), \qquad x\in[-1,1].
\]

### Constants & Parameters
\[
\nu=\frac{1}{100\pi}.

### Expected Physics
Nonlinear steepening of the sine wave with viscous regularization; no discontinuous shocks (viscosity smooths gradients), but sharp gradients form near the inviscid shock time scale.

## 2. Strategic Methodology

### Can obtain an exact solution or similar?
Yes. Viscous Burgers admits an analytical solution via the **Cole–Hopf transform**, which is equivalent to an exact **Method of Characteristics template** acting on the transformed linear heat equation.

Key transform:
- Define a potential \(\phi\) with \(u=-2\nu\,\partial_x(\ln \phi)\).
- Then \(\phi\) satisfies the heat equation
\[
\partial_t \phi = \nu\,\partial_{xx}\phi
\]
with periodic boundary conditions.
- From the initial \(u(x,0)\), construct
\[
\phi(x,0)=\exp\!\Big(-\frac{1}{2\nu}\int^{x} u(\xi,0)\,d\xi\Big)
=\exp\!\Big(-\frac{1}{2\nu}\int^{x}(-\sin(\pi \xi))\,d\xi\Big)
=\exp\!\Big(-\frac{1}{2\nu}\cdot \frac{\cos(\pi x)}{\pi}\Big)
\]
(up to an arbitrary multiplicative constant, irrelevant for \(u\)). With \(\nu=\frac{1}{100\pi}\),
\[
\phi(x,0)=\exp\!\big(-50\cos(\pi x)\big).
\]
- Evolve \(\phi\) exactly in Fourier space (heat kernel), then reconstruct \(u\) from \(u=-2\nu\,\partial_x\ln\phi\).

**Main Method selection (mandatory):** Method of Characteristics (Analytical/Exact) via Cole–Hopf + Fourier heat evolution. This yields machine-precision ground truth on the periodic domain.

```julia
# %% [markdown]
# ## Cell 2: Core Analytical Solver Definition
# 
# ## Algorithm: Cole-Hopf Transform with Spectral Evolution
# The function `solve_viscous_burgers_colehopf` computes the exact solution for the Viscous Burgers' equation.
# 
# ### Logic Flow:
# 1.  **Cole-Hopf Transform**: Maps the nonlinear Burgers' equation to the linear Heat equation via $u = -2\nu \partial_x (\ln \phi)$.
# 2.  **Initial Potential**: For $u(x,0) = -\sin(\pi x)$, the potential is $\phi(x,0) = \exp\left(-\frac{1}{2\pi\nu}\cos(\pi x)\right)$.
# 3.  **Spectral Evolution**: Evolves $\phi$ in Fourier space using the exact heat kernel $\hat{\phi}(k,t) = \hat{\phi}(k,0)e^{-\nu k^2 t}$.
# 4.  **Reconstruction**: Computes $u(x,t)$ using spectral derivatives and the inverse transform.
# 
# This method provides machine-precision results on periodic domains.

# %%
using FFTW

"""
    solve_viscous_burgers_colehopf(x_in, t, nu)

Analytical solution for 1D Viscous Burgers' equation: u_t + u u_x = nu * u_xx
Initial condition: u(x,0) = -sin(pi * x)
Domain: x in [-1, 1] (Periodic)

Uses the Cole-Hopf transformation and Fourier Spectral method.
"""
function solve_viscous_burgers_colehopf(x_in, t, nu)
    # Work on a copy
    x = collect(Float64, x_in)
    N = length(x)
    L = 2.0 # Domain length [-1, 1]
    
    # 1. Construct Initial Potential phi(x,0)
    # Formula: phi = exp( -1/(2nu) * Integral(u0) )
    # For u0 = -sin(pi*x), Integral = cos(pi*x)/pi
    # Exponent = -1/(2*nu*pi) * cos(pi*x)
    # For nu = 1/(100pi), amp = 50.0
    amp = 1.0 / (2.0 * nu * pi)
    phi = @. exp(-amp * cos(pi * x))
    
    # 2. Move to Fourier Space
    # Use rfft for efficiency with real inputs
    phi_hat = rfft(phi)
    
    # 3. Define Wavenumbers k
    # k_n = 2*pi * n / L
    # rfftfreq(N) returns n/N. Multiply by N to get n.
    k = (2.0 * pi / L) .* rfftfreq(N) .* N
    
    # 4. Evolve in Time (Heat Kernel)
    # phi_hat(t) = phi_hat(0) * exp(-nu * k^2 * t)
    decay_factor = @. exp(-nu * (k^2) * t)
    phi_hat_t = phi_hat .* decay_factor
    
    # 5. Compute Derivative in Spectral Space
    # d/dx corresponds to multiplication by im * k
    phix_hat_t = (im .* k) .* phi_hat_t
    
    # 6. Transform back to Physical Space
    phi_t = irfft(phi_hat_t, N)
    phix_t = irfft(phix_hat_t, N)
    
    # 7. Recover u(x,t)
    # u = -2 * nu * phi_x / phi
    u_val = @. -2.0 * nu * (phix_t / phi_t)
    
    return u_val
end
```

```julia
# Linear operator: ν * ∂²x
# In Fourier space: ν * (-k²)
linear_coeffs = ν .* ops.∂²x
L_matrix = Diagonal(linear_coeffs)
L_op = MatrixOperator(L_matrix)

# Nonlinear operator: -u * ∂x u = -0.5 * ∂x(u^2) (Conservative form)
function nonlinear_operator!(dN, u_hat, p, t)
    ops = p
    u = real(ifft(u_hat))

    flux = 0.5 .* u.^2
    
    # Transform flux to spectral space
    flux_hat = fft(flux)
    
    # Compute derivative in spectral space: -ik * flux_hat
    dN .= -ops.∂x .* flux_hat
end

prob_split = SplitODEProblem(L_op, nonlinear_operator!,
```
